# 提示词优化首批交付记录

日期：2026-11-16。用户授权优化提示词工程；基线 `b36ccdb`，局内外 UI 保持原样。

## 已实施

1. **正文最终预算包含预设。** 预设前置条目、深度条目和衔接说明计入实际组装后的输入估算。宏只展开一次，裁剪过程复用结果，不重复抽取随机宏。实际输出上限取预算、连接设置、预设三者的较小值。无法裁剪到预算内时，在正文生成前停止，不发送已知超预算的正文请求。
2. **抽取目录分层。** 保留完整物品与义体的稳定 ID、名称、类别及参考价格索引；能力长说明只展开玩家持有、装着的义体、现场或点名人物的装备、现场货架，以及输入和正文提及的物件。世界登记的独立物件也进入索引，交给 NPC 后身份不丢失。目录外物件仍可登记，不将相关性筛选变成存在白名单。
3. **抽取移除纯创作素材。** 转折、两难和后果创作参考不再发送给记账阶段；正文阶段照常保留。动态物件详情放在用户消息中，静态简短目录留在系统消息。
4. **有限批量修复。** 同阶段的非法状态条目集中修复一次，合法条目不返回模型重写。判断与抽取各最多一次，顶层 JSON 修复也占同一额度，整轮最多两次。每次输入约 8,000 token、输出上限 2,048 token；可选建议格式错误直接丢弃，不挤占事实修复额度。未知键、重复修复键和未通过原 schema 的修复不会生效。
5. **失败明确保留。** 判断的关键字段必须明确存在；无法修复时停止本轮，不将错误默认为可行。抽取必须提供 changes 数组，允许空数组，缺失不能算成功。未修复的事实保留未完整结算标记，阻止后续场外演化和摘要把该轮当成完整事实。
6. **规则和示例遵循沙盘因果。** 清理旧 HP、人性点数、每一步必须付代价、每次后果必须换花样等表述；允许准备充分时顺利成功、平静生活持续。持续伤口不按轮重复新增，五感描写按场面需要使用。

## 本地估算

| --- | ---: | ---: | ---: |
| 日常交谈 | 38,751 | 21,763 | 43.8% |
| 威尔逊枪店 | 38,296 | 24,488 | 36.1% |

使用项目 `estimateTokens`，不是模型精确分词或真实计费；也不是整轮三阶段的降幅。日常展开 3 条能力说明，枪店展开 40 条，全部身份索引均保留。复现脚本与结果在 `.run/prompt-optimization-20261116/catalog-token-comparison.ts` 和同名 JSON。

## 当前边界

普通自由行动仍为判断、正文、抽取三次调用。场景摘要与场外演化的调用条件维持本轮之前的实现。两次调用路径、摘要合并、事件增量调度需要独立的质量对照验证，本轮没有宣称已实现。

预算与修复 token 使用现有近似估算，没有新增精确 tokenizer、上游缓存计费统计或独立思考预算。判断、抽取的整份请求尚未实现与正文同等的动态总窗口裁剪。连接和预设配置没有改写，也没有实际付费模型对照运行。
