# 服装扩充与装备实效化改造计划

- **状态**：已完成（2026-11-27）
- **背景诊断**：
  1. **服装库偏少且断档**：目前武器 100 件、义体 187 件，但 6 格服装总共仅 27 件（全部为普通/精良白绿装，无稀有/史诗/传说/不朽装），缺少战术防弹衣、公司高定、各帮派特色外套、高阶潜网装与原作经典标志服装；
  2. **服装与装备缺少实际机制效果**：
     - `inventory/schema.ts` 与 `inventory/status.ts` 硬编码「服装没有护甲」，且 `status.ts` 既未将穿着的 `ability` 传给模型，背包行也只输出英文 `id×n`（不含中文名与功能说明）；
     - 潜网服不联动黑客热负荷、工装/胸挂不增加携带上限、防弹背心/头盔不提供战斗防护事实、隐匿/伪装装不联动潜行与识别；
  3. **实用功能装备偏少**：缺少战术携行具、潜行/渗透/电子干扰设备、高阶医疗与烟雾弹等常用夜之城装备。

## 模块 A：服装与装备「真实系统效果」打通（`core` + `web`）

### 1. 结构化装备能力字段（`packages/core/src/systems/inventory/schema.ts`）

在 `ItemDefSchema` 中为服装与功能装备增加清晰的定性/轻机制字段（坚持本作无 RPG 膨胀数值、以物理与机制事实结算的原则）：
- `carryBonus?: number`：携带上限加成（如多袋工装裤 +1、战术胸挂 +3、重装携行包 +4），直接计入 `loadoutSummary` 的 `carryMax`（与义体 `carryBonus` 统一累加）。
- `protection?: { level: "light" | "ballistic" | "heavy"; coverage: ("head" | "torso" | "limbs")[] }`：防护档位与部位（防划伤碎弹 / 防手枪微冲口径 / 防步枪与破片），穿着后生效。
- `netThermalRelief?: number`：潜网散热增益（如基础潜网服 1、军规/精工潜网服 2、冷却头环 1），在 `hacking` 系统中真实减缓热负荷增长与加快冷却。
- `hazards?: ("toxic" | "emp" | "fire" | "thermal" | "flash")[]`：环境防护（滤毒/抗电弧/阻燃/隔热/防闪光致盲）。
- `stealthTags?: ("quiet-step" | "face-conceal" | "low-profile" | "thermal-dampen")[]`：潜行与身份隐匿词条（静音落脚、遮蔽面部防监控人脸识别、低调融入、抑制热信号）。
- `factionDisguise?: string`：特定势力制服伪装标识（如 NCPD / 荒坂 / 军用科技 / 创伤小组 / 各帮派）。

### 2. 跨系统状态联动与提示词透出

- **`inventory/view.ts`**：计算并投影 `inventory.gearEffects`（当前穿着 + 随身装备汇总的防护部位档位、携带上限加成、潜网散热、环境抗性、潜行词条、势力伪装）。
- **`inventory/status.ts`**：
  - 去掉「穿着没有护甲」的硬编码，改用实际汇总的防护/散热/抗性/隐匿/伪装 + 每件穿着的简明 `ability` 喂给模型；
  - 背包非武器物品不再只写英文 `id×n`，改为输出 `中文名［id］×n（功能摘要）`，确保工具包、撬锁器、干扰器、工牌等在裁决与叙事中真实发挥作用。
- **`hacking` 联动**：读取当前穿着的 `netThermalRelief`（不引入循环依赖，直接解析 `inventory` 切片与目录），在快速破解升温时降低热量增量。
- **`health` / `combat` / `perceived` 联动**：
  - `perceived.ts` 读取面部遮蔽（`face-conceal`）与势力伪装（`factionDisguise`），影响路人/监控辨识；
  - `combat/status.ts` 提示玩家当前躯干/头部防护档位（如「躯干防弹护甲·防手枪/微冲口径」），作为交火受伤档位裁决的硬事实依据；
  - `med-kit`（急救绷带包）与治疗品补全 `ability` 说明，支持更清晰的非战斗急救体验。

### 3. 前端效果可视化（`apps/web/src/features/story/InventoryPage.tsx`）

- 在物品栏「随身」视图顶部增加紧凑的 **当前装备生效效果总览条**（如 `躯干防弹`、`携带 +3`、`潜网散热 +2`、`面部遮蔽`、`滤毒`）。
- 选中服装或功能装备时，在详情卡内以结构化效果徽章醒目展示其防护、携带加成、散热、抗性与潜行效果。
