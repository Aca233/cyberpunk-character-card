# 角色入口与角色库交互流程改造方案

> 状态：已完成
> 创建日期：2026-11-23

## 问题

原先点击主菜单「角色」或新建存档里的「管理角色」进入 `/characters` 后，默认直接展示空白的 5 步角色创建工作台，已有角色被折叠在顶栏的「角色库」抽屉里，导致管理与浏览已有角色的流程倒置。

## 改造设计

### 1. `/characters` 改为「角色库总览 → 编辑/创建工作台」两段式流程

- **默认视图（`roster` 角色库总览）**：
  - 展示所有本地「自建角色」与「官方预设模板」的卡片网格（立绘缩略图、姓名/外号、出身、特质与义体计数、简介摘要）。
  - 顶部提供搜索筛选、**`＋ 新建角色`**（主按钮）、`导入 JSON`、`返回主菜单`。
  - 每张角色卡支持点击进入编辑/查看、快捷导出 JSON、以及自建角色删除（复用确认弹窗）。
  - 若 `localStorage` 中有上次中断的未保存草稿，在角色库顶部以提示条呈现（`继续编辑` / `丢弃草稿`），既不丢失草稿，也不强行跳转创角页。
- **工作台视图（`editor` 创建/编辑工作台）**：
  - 点击 **`＋ 新建角色`** 或任一角色卡后进入 `CharacterCreator`。
  - 顶栏新增 **`← 返回角色库`** 按钮（带未保存修改确认保护），同时保留快捷切换抽屉与导出/返回主菜单。
  - 删除当前正在编辑的角色后自动回到角色库总览，而不是切到空白建卡表。
- **路由参数直达**：
  - `/characters`：默认打开角色库总览；
  - `/characters?new=1`：直接进入新建角色工作台；
  - `/characters?id=<id>`：加载指定角色进入编辑工作台。

### 2. 主菜单「角色」舞台同步优化

- `MainMenu.tsx` 点击左侧 **`角色`** 不再直接跳转新页面，而是同「新建存档」「读取存档」「界面主题」一致留在主菜单，右侧舞台直接展示全部角色档案卡片（支持搜索筛选、点击卡片直达 `/characters?id=<id>` 编辑、**`＋ 新建角色`** 直达 `/characters?new=1`、**`管理全部`** 进入完整 `/characters` 角色档案库）。

## 验收清单

- [x] 点击主菜单「角色」进入 `/characters` 时先看到角色库总览，而非空白建卡表
- [x] 点击「＋ 新建角色」进入 5 步创建工作台；点「← 返回角色库」可带脏检查返回列表
- [x] 点击任一已有角色卡可加载其档案编辑；删除自建角色后回到角色库列表
- [x] 存在未保存草稿时在角色库顶部提示恢复或丢弃，不劫持入口
