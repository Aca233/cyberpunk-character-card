# 设置界面美化与体验优化计划

- **日期**：2026-11-22
- **状态**：进行中
- **范围**：`apps/web/src/features/settings/` 与 `apps/web/src/ui/togglecheck.module.css`
- **视觉红线**：沿用 2077 原作贴图（`NineSlice`、`Asset`、`CellFrame`、`FrameBox`、`fx.grid`）与 `tokens.css` 统一暖暗紫黑表面色阶；不使用 CSS 渐变与 `backdrop-filter`；交互指针统一使用 `var(--cp-cursor-hand)` / `var(--cp-cursor-invalid)`；完整兼容 `prefers-reduced-motion`；保留全部既有接口契约与用户已确认的功能边界（如「设为叙事模型」「设为辅助模型」「设为文生图模型」独立按钮不合并）。

---

## 现状问题诊断

1. **宽屏排版左偏失衡**：顶栏、页签栏、底栏撑满全宽，而正文内容（`max-width: 75rem`）靠左排布，1440px+ 屏幕右侧大面积空洞。
2. **冷蓝灰表面色阶漂移**：设置页与开关组件仍残留大量旧版冷蓝灰硬编码（`rgb(14 14 23 / ...)`、`rgb(12 10 18 / ...)`），与 `tokens.css` 暖暗紫黑体系不协调。
3. **页签缺少即时状态感知**：无法在不切换页签的情况下一眼识别「模型未就绪」「预设已启用」「剧透调试已开启」。
4. **模型连接表单交互粗糙**：
   - 顶部状态条 3 个角色挤成一行小芯片，视觉权重弱；
   - 新增连接时的 7 种接入方式藏在原生下拉框里，不便对比选择；
   - API 密钥输入缺少临时明文预览切换；
   - 高级参数折叠区无样式、折叠时看不到当前参数摘要；
   - 底部通知条无关闭按钮，普通操作与破坏性操作混排。
5. **酒馆预设列表筛选能力弱**：几十条提示词条目仅支持关键词搜索，无法一键筛选「已开启 / 已关闭」，角色与元信息混为一串灰色文字。
6. **叙事偏好单栏过长、利用率低**：四个大卡片纵向堆叠，4 个文生图提示词文本框单列拉长，缺少字数计数；「城里的动静」仅 4 个选项却藏在下拉框里。
7. **上下文调试页信息密度高但缺乏导航与可视化**：全部区块常驻展开导致页面冗长；筛选栏与导出按钮割裂；token 预算纯文字难以快速扫视；载入模块为长串纯文本。

---

## 分步实施方案

### Step 1：计划留存
- 创建本文档 `docs/plans/settings-ui-redesign.md`。

### Step 2：设置壳层、居中容器、色阶统一与开关微动效
- **文件**：`SettingsScreen.tsx`、`settings.module.css`、`apps/web/src/ui/togglecheck.module.css`
- 统一顶栏、页签栏、主体容器、底栏为居中限宽 `max-width: 1360px`。
- 叠加低透明 `fx.grid` 点阵肌理，将所有冷蓝灰表面色迁移到 `--cp-surface*` / `--cp-line-*`。
- 顶栏右侧增加实时配置摘要胶囊；4 个页签增加序号编码（`01`–`04`）与实时状态指示点；底栏增加细分隔线与快捷键/本地存储提示。
- `ToggleCheck` 开关底色统一至 `--cp-surface-strong`，滑块增加平滑位移动画。

### Step 3：模型连接工作台升级
- **文件**：`ModelSettings.tsx`、`model-settings.module.css`
- 顶部配置状态横幅重构为 3 格战术角色槽位卡（叙事 / 辅助 / 文生图），展示连接名、模型名与状态灯，点击可直达对应连接。
- 左侧连接列表增加数量计数、协议徽章、选中态青色左侧发光标识；修正 `.modelOption` 自定义光标。
- 新增连接提供切角预设速选卡片网格；API 密钥字段增加状态徽章与临时显示/隐藏切换（仅针对未保存输入）；保留 3 个独立角色分配按钮并增强激活态区分。
- 高级参数改造成战术折叠卡并在摘要行实时回显当前参数；底部「可选验证与管理」区分常规与危险操作组，测试结果升级为带延迟徽章的状态卡；通知条支持手动关闭。

### Step 4：酒馆预设工作台升级
- **文件**：`PresetSettings.tsx`、`settings.module.css`
- 顶部状态条与左侧列表视觉对齐模型连接工作台，空态提供醒目导入入口。
- `ToggleList` 增加状态筛选胶囊（`全部` / `已开启` / `已关闭`），提示词条目显示彩色角色徽章（系统 / 用户 / 助手）与字数/深度标签。
- 展开的 `EntryEditor` 增加未保存修改提示标签，删除折叠区统一战术折叠风格。

### Step 5：叙事偏好双栏重构与分段控件
- **文件**：`NarrativeSettings.tsx`、`settings.module.css`
- 桌面端顶部状态摘要条 + 上排双栏布局（左：呈现开关与调试开关；右：城市节奏 4 档分段选择器）+ 下排全宽 2×2 文生图提示词网格（移动端自动单栏）。
- 「城里的动静」升级为 4 档战术分段单选组（`radiogroup`），一键切换。
- 4 个文生图提示词框补充实时字数统计（`N / 800`）与「已恢复默认」短时反馈；开启剧透后在调试卡提供一键跳转至上下文调试分页按钮。

### Step 6：上下文（调试）视图重构
- **文件**：`SettingsScreen.tsx`、`settings.module.css`
- 居中美化剧透门禁卡；整合存档选择、轮次选择与「导出评测用例」为统一顶部工具栏。
- 指标卡迁移暖暗色阶，载入模块改为胶囊标签流；token 预算分项增加纯色进度条。
- `Section` 支持折叠展开（带旋转箭头），场景摘要与人物共同记忆编辑控件统一暖暗边框与焦点样式。

### Step 7：静态校验与收口
- 执行 `pnpm typecheck`、`pnpm lint`、`pnpm check-assets`（按项目约定不自动运行测试，交由用户验收）。
- 更新本文档状态并完成最终提交。
