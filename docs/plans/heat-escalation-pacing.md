# NCPD 通缉升星节奏优化计划

## 痛点根因

1. **同场冲突封顶只认 `entry.at === now`**：一场持续 3–5 回合（间隔 2–15 分钟）的交火每回合时间戳都不同，封顶每回合自动清零，导致同一场战斗连叠 3–4 次直接从 0 星飙到 4–5 星（挂永久悬赏 + 暴恐机动队）。
2. **`inferEventVictim()` 兜底默认按无辜平民 (`civilian`) 算**：模型未填 `victim` 且目标为雇佣兵/枪手/马仔/黑客/匿名人名时，被当成「屠杀无辜平民」，单次直接 `+2.5`~`+3` 星。
3. **非暴力类事件（`publicHack` / `theft` / `vandalism`）未区分对象与城区安保**：低安区打帮派放个快速破解或偷件东西就直接 `+1` 整星。
4. **单次与同场增幅过陡**：`kill` 基础 `+2`、公开再 `+1`，单回合即可 0→3 星，跳过 1–2 星缓冲阶段。
5. **抽取器提示词缺少持续交火去重约束**：多回合持续战斗中抽取器容易每回合重复补发 `publicViolence` / `publicHack` / `kill`。

## 调整方案

- [x] **阶段一：重构热度推导与同场时间窗封顶（`packages/core/src/systems/heat/apply.ts`）**
  - 引入 25 分钟同场冲突窗口（`INCIDENT_WINDOW_MINUTES = 25`）累计封顶，阻止多回合同一场交火反复叠星；
  - 扩充武装/帮派关键词并将无法辨识的匿名对手归入中性 `unknown` 档（不再误判为无辜平民）；
  - 下调单次热度增量（全为 `0.5` 倍数满足 schema 约束）：`publicHack` 针对帮派/交火默认不涨星，偷窃/破坏低中安无报警 `+0.5`，帮派火并同场封顶 `+0.5`~`+1.5`，企业/平民/袭警单次 `+1`~`+1.5`、同场封顶 `+1.5`~`+2`，让 1★→2★→3★→4★→5★ 有清晰递进节奏。
- [x] **阶段二：强化抽取器防刷星指令（`packages/core/src/systems/heat/prompt.ts`）**
  - 明确持续交火不要每回合重复发 `event`（仅在首次闹大、报警或重大升级时发）；常规无线快速破解不发 `publicHack`；未确认无辜平民的武装对手统一归 `gang`。
- [x] **阶段三：静态检查与验收**
  - 运行 `biome lint .`、5 包 `tsc --noEmit`、`tsx tools/check-data.ts`。
