# 夜之城欧元（€$）真实价值与经济闭环方案

- **状态**：已完成（真实化收口，2026-11-27）
- **设计原则**：不做破坏沉浸感的“手游一键商城按钮”，一切花钱行为回归夜之城的物理现场与人情因果。

## 已落地内容

1. **现场给同行搭档花钱配装 / 装义体**（`inventory/actions.ts` / `cyberware/actions.ts` / `Shop.tsx` / `Ripperdoc.tsx`）：
   - 玩家与同行同伴同时在商店或义体医生诊所时，可直接在界面切换「给自己 / 给同伴」，花玩家欧元当场为同伴购入装备或动手术装义体，即时写入同伴 `body` 并参与实战裁决。
2. **重度义体诊所神经校准维护**（`economy/schema.ts` / `economy/view.ts` / `cyberware/actions.ts` / `Ripperdoc.tsx` / `TrackerPanel.tsx`）：
   - 活跃神经承载 ≥ 18 或装有 FBC 全身底盘时，每 14 个游戏日需去**义体医生诊所**坐上手术椅做一次神经校准维护（1,500€ / 3,500€，按诊所倍率与势力态度浮动，敌对诊所拒诊）；
   - 追踪面板「账务与欠款」仅负责到期/逾期提醒，身处诊所时提供「打开诊所」入口，绝不隔空远程校准；逾期会写入【当前状态】并在裁决/正文中表现为耳鸣、手抖与排异干扰。
3. **经济体面与剧情花钱通道自然融入叙事**（`economy/view.ts` / `economy/status.ts` / `economy/prompt.ts`）：
   - 综合余额、房产、座驾与创伤会籍在【当前状态】呈现自然的生活体面背景（无游戏段位徽章），影响门卫、酒保、中间人与黑帮的态度和开价；
   - 买据点情报、托关系消星、花钱摆平仇怨、黑市订稀缺货统一走真实对话或全息私信，由中间人按自身势力范围、交情、报价与交接时间在剧情里真实推进。
