# 玩法深度扩展设计方案

> 状态：已搁置（2026-11-26 仅为头脑风暴备忘，暂不实施）  
> 核心原则：严格延续项目「**代码管事实账本与物理边界，AI 管即兴叙事与裁决，不引入固定数值公式**」的设计哲学；优先复用现有 34 套系统骨架，以最小改动换取最大玩法闭环提升。

---

## 一、模块 A：多剧本开局 + 创意工坊「剧本包」（推荐首期）

### 解决什么痛点
- [openings.ts](file:///c:/cyberpunk-character-card/packages/content/src/openings.ts) 目前只有 1 个 `sandbox-2077` 自由沙盘开局，新玩家前几轮容易缺少方向感；
- 引擎 [game.ts](file:///c:/cyberpunk-character-card/packages/core/src/game.ts) 已原生支持 `openings[]`、`meta.opening`、`deadlines`、`jobs`、`gear`、`eddies`、`location`、`premise`，几乎零底层返工即可开启多剧本；
- 让创意工坊支持打包「剧本开局」，把长期内容产能交给玩家社区。

### 具体设计
1. **内置 4 套风格迥异的可选开局（建档时自由切换）**
   - `sandbox-2077`：**夜之城自由沙盘**（保留现有无死线自由体验）。
   - `debt-7days`：**七日还债·霓虹催命** — 开局欠歌舞伎高利贷 15,000€$（写入 `deadlines` 7 天倒计时 + 1 名债主宿敌预备 NPC），迫使玩家一进城就跑中间人、打地下拳赛或干黑活凑钱。
   - `dogtown-lockdown`：**狗镇封锁线求生** — 出生在狗镇，幽冥犬全区盘查，开局自带 1 份烫手加密芯片（`chipContents`）和 1 个正在发酵的逃离/脱手委托。
   - `corpo-burn-notice`：**公司清算·身份抹除** — 刚被荒坂/军用科技内部清洗，账户清零、旧住所被封、通缉/公司敌对起手，靠仅存的 1 个旧识与随身装备绝地反击。
2. **创意工坊协议扩展（`WorkshopPackSchema`）**
   - 新增可选字段 `openings: WorkshopOpeningSchema[]`（最多 5 个），允许包含：标题、时代/氛围简介、出生点、初始资金修正、开局倒计时、初始委托（`jobs`）、限定或附带包内 NPC/物品/芯片。
   - 玩家在社区广场订阅「剧本包」后，建档时的「选择开局」列表自动出现该剧本；支持在「AI 一句话生成」里直接生成剧本包。
3. **UI 改动**
   - 创角完成点「进入夜之城」前的建档弹窗里，增加横向卡片选择「开局剧本」（默认选中自由沙盘，不增加额外步骤）。

## 二、模块 B：干大票（Heist）筹备板 + 随行搭档分工/分赃

### 解决什么痛点
- 现有 `npc.following`（[npc/actions.ts](file:///c:/cyberpunk-character-card/packages/core/src/systems/npc/actions.ts)）已实现随行转场、占车位、防屏幕外暴毙；
- 现有 `jobs`（[jobs/schema.ts](file:///c:/cyberpunk-character-card/packages/core/src/systems/jobs/schema.ts)）是一般单人委托；
- 缺的是《赛博朋克》最具灵魂的**「筹备一票大的 → 拉随行搭档分工 → 按筹备成果进场 → 结算分赃与人情」**闭环。

### 具体设计
1. **在 `JobSchema` 上轻量化扩展 `heist` 子结构（不另起一套臃肿系统）**
   - 只有高风险（`risk >= 4`）或明确立项为「大票」的委托才挂载 `heist`：
     - `phase`: `"prep" | "exec" | "aftermath"`（筹备 / 进场执行 / 善后分赃）
     - `intel`: `readonly { id, label, acquired: boolean, detail }[]`（已踩到的情报：蓝图、换班表、子网入口、内应口令；筹备阶段通过潜网、买情报、踩点或超梦逐条点亮）
     - `crew`: `readonly { npcId, role: "netrunner" | "solo" | "driver" | "face" | "tech", cutPercent: number, status }[]`（正式拉进这票的搭档，与 `npc.following` 联动）
     - `escapePlan`: 撤离方案文本（如「恶土接应车」「Delamain 通道」「暗渠潜逃」）
2. **随行搭档日常互动补强（基于 `npc.following`）**
   - 新增 2 个无模型开销的 UI 快捷操作：
     - **递交物品/治疗品给随行搭档**（如把回血针、消音枪、护甲递给队友，写入 `npc.body.gear` / 治伤）；
     - **进场前一键召集大票成员同行**（同城且无死仇的已签约小队成员到场汇合）。
3. **分赃与后果闭环**
   - 大票结束时代码按 `cutPercent` 自动算应分欧元：足额分赃加好感与口碑（`deeds`），克扣或黑吃黑直接触发翻脸/记仇/升级 `nemesis` 宿敌！
4. **叙事联动**
   - 进场（`phase === "exec"`）时，提示词自动注入「已点亮的情报清单 + 小队分工表 + 撤离方案」；筹备越充分，AI 叙事里可利用的捷径/掩护越真实，反之盲冲就会直面未排查的炮塔、黑冰与增援。

## 三、模块 C：安全屋据点设施 + 中后期传奇终局目标

### 解决什么痛点
- 买完顶级义体、武器和跑车后欧元溢出，安全屋只剩睡觉交租，缺少长期驱动力。

### 具体设计
1. **安全屋设施升级（扩展 `HomeSchema.upgrades`）**
   - 每处自有/长租安全屋可花费高额欧元（15,000 – 120,000€$）添置真实功能设施（零数值加成，全是**真实能力解锁**）：
     - **潜网冷浴椅**（`netrun-chair`）：无需去黑客窝点，在家直接安全发起深度潜网（`dive`），且热负荷冷却更快。
     - **私人改枪与调校台**（`workbench`）：在家自由拆装全部武器改装件（含通常需枪匠处理的锁定改装/精调）。
     - **自动急救医疗舱**（`med-bay`）：回家即可处理 `heavy` 重伤与清除毒素/义体轻微排异，省去高热度下冒风险去诊所。
     - **匿名洗钱与加密终端**（`anon-rig`）：可接暗网匿名高危悬赏、降低通缉残留扩散速度、远程安全备份芯片。
     - **来生级装甲车库**（`armored-garage`）：为名下车辆加装防弹镀层、伪造车牌（换牌消警报痕迹）与大容积隐蔽后备箱。
2. **中后期「传奇里程碑 / 自选终局线」（挂在 `chronicle` + `character.deeds`）**
   - 玩家可在人物档案里立下 **1 个长期野心（Ambition）**（可随时改，也可无目标纯漫游）：
     - **来生传奇**：积累 ≥ 3 条 `city` 级全城事迹并完成至少 1 场 5 星大票 → 解锁在来生拥有专属特调酒名与传奇结局选项。
     - **逃离夜之城**：攒够 **250,000€$** 轨道航空月票（或通过阿德卡多/黑市走私线）→ 触发带告别演出与人物尾声的「登月 / 远走高飞」主动通关结局。
     - **地下教父**：与任一帮派/中间人达到 `family` 并主导至少 2 次城区地盘易主 → 解锁幕后派单与城区收税/庇护网络。

## 四、模块 D：街头活计公告板 + 潜网 / 超梦轻量交互条

### 解决什么痛点
- `sidegigs.ts` 仅 6 场一次性比赛，且 `GigsPanel.tsx` 为空文件，玩家看不到城里有什么街头活可干；
- 潜网深入（5 层）和超梦分析（3 层）底层极完整，但界面上缺少直观控制条。

### 具体设计
1. **启用 `GigsPanel.tsx`（街头活计与赏金看板）**
   - 整合三栏一眼可见：
     - **当前委托与大票筹备**（含倒计时提醒与一键定位地图）；
     - **地下拳赛 & 街头赛车巡回**（扩充并支持卫冕/挑战赛，标明地点、押金、奖金、一键导航出发）；
     - **城区 NCPD 悬赏 / 暗网快单**（按当前城区动态刷出可重复的小型实战单：清理清道夫窝点、截获走私车、黑入公司中继站，提供稳定的日常赚钱与刷声望循环）。
2. **潜网 & 超梦沉浸交互条（挂载在输入框上方，仅在对应状态出现）**
   - **超梦编辑态**：显示当前作品时间轴片段（`passages`）+ 一键切换「视觉层 / 音频层 / 热成像层」按钮 + 已发现线索列表（点击自动填入对应调查指令，无需手敲格式）。
   - **潜网深入态**：显示当前所在层级（1–5 阶）、热负荷色条、守在肉身旁的护卫姓名，以及快捷操作按钮（「向下渗透一层」「扫描节点」「提取数据」「紧急断开」）。

## 推荐实施顺序（小步快跑，每期独立可玩）

1. **第一期（最快见效）**：**模块 A（多剧本开局 + 工坊剧本包）** — 复用现有 `GameOpening`，改动集中在 `openings.ts` + `workshop.ts` + 建档开局选择器，1 次迭代即可上线。
2. **第二期（强化日常探索）**：**模块 D（街头公告板 + 潜网/超梦快捷交互条）** — 把已有系统的可玩性直接浮出水面。
3. **第三期（核心高潮玩法）**：**模块 B（大票 Heist 筹备板 + 随行小队分工分赃）** — 让随行搭档和委托系统真正拧成一股绳。
4. **第四期（长线耐玩度）**：**模块 C（安全屋据点设施 + 传奇野心与主动终局）** — 补齐大后期花钱与收官体验。
