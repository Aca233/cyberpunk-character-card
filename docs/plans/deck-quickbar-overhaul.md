# 输入框接入仓快捷破解栏（DeckQuickbar）优化计划

## 痛点

1. **向下展开挤压底部布局**：当前 `DeckQuickbar` 渲染在输入框正下方，紧贴底部 `KeyBar`，展开时会把输入框顶跳且内容多时贴底局促。
2. **首次打开空白、多一步盲点**：点击接入仓按钮时强行清空选中目标，面板只显示一排目标名，玩家必须再点一次目标才能看到任何破解程序。
3. **程序按钮信息量过少**：仅显示程序名和极小的两字提示，破解效果（`effect`）、分类（控制/隐蔽/伤害/终极）、接口前提（`targetRequirement`）以及目标扫描信息（`role`、`netLabel`、`chromeSummary`、`activeEffects`）全藏在鼠标悬停 `title` 里。
4. **视觉简陋、交互细节欠缺**：纯平小排按钮缺少 2077 扫描仪与快速破解卡片的层次感；热负荷仅有纯文字 `热 2/6`；焦点不在文本框时按 `Esc` 无法关闭面板。

## 优化方案

- [x] **阶段一：重构 `DeckQuickbar.tsx` 结构与交互**
  - 新增顶部战术 HUD 栏：接入仓型号 + 分段神经热负荷进度槽（支持黑墙猩红皮肤）+ 反追踪警报徽标 +「管理插槽」快捷跳转 + `×` 关闭。
  - 保留紧凑目标选择栏（按敌对/同伴/在场/环境区分色调并显示已破冰标记），并在下方新增 **Kiroshi 目标扫描情报条**（展示身份、破冰状态、网络链路、义体概况与已生效破解胶囊）。
  - 快速破解区升级为 **2077 原生切角战术卡片网格**（使用 `qh.cellBg` / `qh.cellFg` 素材）：展示程序名、类别标签、热负荷等级、精炼效果说明、接口前提与锁定原因；
  - **严格按目标类型与 ICE 状态过滤可用项**：
  - **理顺 Kiroshi 义眼扫描操作逻辑**：
    - `StoryScreen.tsx` / `Corners.tsx`：移除反直觉的「按住 Tab 闪现且不触发真实扫描」双态割裂逻辑，统一为 **点按 `Tab` 或点击扫描按钮切换扫描模式，开启时自动全扫在场目标**（无完好义眼直接 toast 提示），再按 `Tab` 或 `Esc` 关闭；
    - `DeckQuickbar.tsx` / `InputBar.tsx`：在接入仓面板内直接提供「义眼扫描」与「全扫 (N)」零回合即时扫描按钮，无需关闭面板再去角落找按钮，扫完当场刷新 ICE、义体与破冰资格；
    - `packages/core/src/systems/npc/body.ts` & `ui-actions.ts`：已扫描人物再次复扫/重复扫描仅静默刷新档案时间戳，不再写入 `notes` 或带入下一轮正文上下文，并对历史重复扫描记录做去重。
    - 选中「现场设备/监控」环境目标时，自动过滤掉仅限义体人目标的芯片（如重启义眼、音波震冲、记忆擦除、阻碍移动、武器故障、过热、连带传染与全部终极破解），仅保留定位/电磁短路等局域网/设备芯片及「破冰入侵 / 接管安防与门禁」。
  - 补全全局 `Escape` 关闭监听（阻断冒泡避免误开暂停菜单）与过载预警提示。
- [x] **阶段二：重写 `deck-quickbar.module.css`**
  - 改为浮升在输入框正上方（`position: absolute; bottom: calc(100% + 10px)`），输入框与底部 `KeyBar` 保持稳定不跳动；增加最大高度与柔和滚动条，适配宽屏/窄屏响应式多列网格。
  - 遵循项目视觉规范（原作九宫格 `notify.itemCellBg`/`Fg` + `qh.cellBg`/`Fg` + `fx.scanlines`，无廉价渐变与 `backdrop-filter`，完整适配黑墙接入仓红黑警戒模式与 `prefers-reduced-motion`）。
- [x] **阶段三：联动更新 `InputBar.tsx`**
  - 点击接入仓按钮展开时自动默认选中优先目标（优先敌对目标，否则首个目标），打开即直接呈现完整扫描情报与破解卡；将 `<DeckQuickbar>` 移至 `composerShell` 前方/内部相对定位锚点。
- [x] **阶段四：静态检查与验证**
  - 已全部通过：CSS Module 类名覆盖检查（51/51 类）、`biome lint .`（700 文件 0 报错）、5 包 `tsc --noEmit` 与 `tsx tools/check-data.ts`。
