# 商店页面视觉美化与体验优化计划

> 状态：已完成（2026-11-22）
> 目标：在既有双栏商店终端基础上，全面升级 `Shop.tsx` 与 `shop.module.css` 的赛博朋克 2077 视觉质感、空间利用率、浏览筛选效率、右侧全息检视台、武器工坊界面与交易确认回执体验，同时确保共用样式的 `AutofixerModal.tsx` 保持完整兼容并同步受益。

## 1. 现状诊断与优化目标

1. **顶部冗余与空间挤压**：`<Panel title={`商店 · ${shop.name}`}>` 与内部商贩横幅 `<h3>{shop.name}</h3>` 重复显示店名；下方工具栏松散占满 3 行，在常规分辨率下压缩了双栏货架的可用高度。
2. **货架浏览效率受限**：仅支持单列纯长列表，缺少双列展柜网格视图、排序能力（价格升降序、稀有度降序）、搜索清空按钮、命中计数与一键重置筛选；缺图武器在买/卖列表回退到两字汉字缩写，未调用 `weaponHudIconOf` 剪影。
3. **视觉纵深与动效落后于全站最新质感**：全站已引入 `useCardTilt` 3D 压铸反光与精修动效，而商店卡片、检视展台与交易确认框仍偏向扁平表单，缺乏黑市/常规态氛围差异、交易后余额跳动反馈与展台全息层次。
4. **右侧检视台与武器工坊层次待精修**：检视台操作按钮未吸底，长文本需滚动；收支信息散落为普通表格行；武器工坊战术参数变化对比与槽位状态视觉不够突出。

## 2. 核心设计方案

### 2.1 商贩终端顶栏与沉浸外框
- `.backdrop` 增加微暗角与柔和背板模糊（`backdrop-filter: blur(6px)`）。
- 取消重复的 `<Panel title>`，改为在商贩头部集成终端标识、类型标签与黑市警示视觉（黑市商店自动切换外框线条为 `--cp-red` 并叠加警示斜纹；常规商店维持 `--cp-yellow`）。
- 放大店主头像框（`64×64`）并叠加角标 POI 图标与微扫描线；欧元余额徽章支持交易后的变动浮字（`-xxx€` / `+xxx€`）与短暂高光脉冲；离开按钮附 `key.esc` 原作按键图标。

### 2.2 紧凑两层控制台
- **主控制条**：左侧为买进货架 / 出手回收 / 武器工坊机械感页签（带数量角标与扫描底线，回收模式附当前可售总估值）；右侧集成搜索框（带清空按钮与 `/` 快捷键）、排序切换（默认 / 价格↑ / 价格↓ / 稀有度↓）与视图切换（展柜网格 / 明细列表）。
- **次级筛选条**：紧凑品类标签 + 稀有度发光色点筛选 + 仅看可买/可收开关 + 命中计数与一键重置按钮。

### 2.3 双视图商品卡片与键盘浏览
- **展柜网格视图（默认，宽屏双列自适应）**：2077 原作商贩陈列风格，包含顶部稀有度光带、左上角品级/不朽徽标、右上角库存/拥有胶囊、中部 `fx.grid` 展盒与高清物品图（武器自动使用 `weaponHudIconOf` 剪影兜底）、底部名称、改件摘要、醒目价格与快捷买卖按钮。
- **明细列表视图**：精修版横向卡片，增大缩略图展盒与信息层次，兼容 `AutofixerModal.tsx` 样式复用。
- 支持键盘 `↑` / `↓` 切换检视项、`/` 快速聚焦搜索框（确认弹窗打开或输入框聚焦时自动让位）。

### 2.4 右侧全息检视台与武器工坊升级
- **3D 压铸全息展台**：接入轻量 `useCardTilt` 与镜面掠射高光，叠加 `fx.grid` + `fx.scanlines` + `fluff.code` 装饰水印与稀有度环境光晕；四角排布品级与库存状态徽标。
- **分层布局与吸底结算栏**：检视台主体独立滚动，底部固定交易账单卡（当前余额 → 交易后余额 / 差额警示）与全宽主操作按钮。
- **武器工坊精修**：左侧武器卡增加槽位占用点阵与战术徽标；右侧参数对比区升级为战术读数仪表卡，悬停改装件时变化项高亮闪烁对比；槽位卡片与改装选项层次更清晰。

### 2.5 交易确认回执弹窗
- `Dialog` 内嵌商品缩略图预览与稀有度色带，下方展示清晰的收支账单（原余额、本次变动、交易后余额）及武器改装战术参数变化摘要。
