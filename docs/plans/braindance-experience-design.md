# 超梦体验与日常消费策划案（轻量版）

状态：待实施；本版整体替换上一版重型方案，删去的机制不列入首版要求。

日期：2026-11-19

## 一、核心定位

**把超梦做成有固定内容、能够正常消费的叙事场景。**

玩家没有委托时，也能去店里挑片、回家重看，或和朋友体验一部作品。消费可以平静地结束，留下实际花费、时间和来往记忆。

首版只做四件事：作品记得住、正文体验自然、钱和时间对得上、看完之后的生活接得上。旅行、演出、运动、职业体验、成年角色的成人娱乐和私人纪念都沿用同一套轻量规则。

## 二、首版玩法

**选片 → 付款或使用已有作品 → 接入体验 → 继续／略写看完／退出 → 结算与记忆。**

| 环节 | 玩家行为与系统回应 |
| --- | --- |
| 选片 | 看简介、问店员推荐、挑已有收藏；同一家店已经确立的作品保持稳定 |
| 开始 | 店内按次消费，或用自己已有的作品和设备播放；实际付款沿用现有交易 |
| 体验 | 正文按作品内容展开，玩家可以自由打断、留意已有细节、与现场人物交流 |
| 继续 | 从当前段落接着体验，不要求每段选择答案 |
| 略写看完 | 正常体验完剩余内容，省略过程描写，游戏时间仍经过剩余观看时长 |
| 退出 | 停在实际看到的位置，保留已发生的时间、消费和有关记忆 |
| 重看 | 引用同一作品的既定内容；有实际播放时正常经过时间，不重复收购片费 |

暂停、改天继续和回看某段，用当前场景与简单段落记录承接，不增加独立播放器状态机。查看已经写出的文字是查阅记录，本身不等于角色又重播了一次。

## 三、作品固定，体验通过正文展开

每部作品最少保留稳定 ID、名称、录制者、简介、时长、事件梗概和已经定稿的片段。作者或系列在内容需要时补充，不要求为每位演职人员建立 NPC 卡。

- 第一次确立作品后，主要事件、录制视角与已呈现事实保持一致；重看不能随玩家追问改剧情。
- 不预先生成整部冗长正文；先固定内容梗概，再按本次体验需要展开，定稿片段持续保存。
- 玩家可以关注记录里已有的内容；没有录到、无法辨认的事情，不为了回答问题临时补出真相。
- 片中人物按原记录行动，不响应播放器外的玩家，也不因玩家观看而成为现实熟人。
- 录制者的情绪作为记录输入存在，玩家如何理解、喜不喜欢由玩家决定。
- 作品内容与现场聊天分开：重看一段作品，不会把上次朋友的插话重新演一遍。
- 确有广告版、删减版等区别时，用清楚区分的作品条目承接，首版不做通用版本管理体系。

文风、篇幅、节奏与描写方式交给写作预设。内置规则只保留世界事实、视角、玩家控制权、知情边界与记账协议，不叠加固定写作示例或感官配额。

## 四、只保留必要状态

| 内容 | 最少记录 | 复用方式 |
| --- | --- | --- |
| 作品 | 是什么、谁录的、时长、固定梗概与已写定片段 | 少量固定内容加正文中确立的新作品，均使用稳定身份 |
| 当前体验 | 正在看哪部、看到哪个段落、已经实际观看约多少游戏分钟 | 简单活动记录，随正常存档保存；不维护秒级游标或观看覆盖区间 |
| 实际消费 | 谁提供、买作品还是店内体验、确认价格、是否已经成交 | 现有报价、物品归属和交易记录 |
| 有关记忆 | 谁一起看过、实际聊过什么、玩家明确说过的评价 | 现有人物共同记忆与场景记忆 |

有实际载体或存储副本才有当前播放来源，沿用已有物品与世界事实；不为超梦另建独立授权系统。设备同样按已有、损坏或无法接入等实际情况判断，不新增设备库存、预约和占用模拟。

作品资料与有关记忆能按店铺、人物和作品召回，支持下次接话；不把无关作品全文常驻每轮上下文。

## 五、钱与时间怎么处理

1. **先确认，再消费。** 询价、看简介、讨论和玩家单方面出价不扣款。店内按次与购买作品使用明确的交易目标，复用既有报价、授权、去重和事件结算。
2. **钱与交付一致。** 付款失败不能写成已买到或已经开始收费体验；重试不能再次扣款。不另造钱包、付款回执或专用退款系统。
3. **只用现有游戏分钟。** 正常观看经过相应时长；中途退出按正文与已结算事实记录实际经过的时间。略写看完只补剩余时长，不能再扣一次整片时间。
4. **继续与聊天分清。** 现实交流时先暂停体验，聊天沿用普通时间处理；回到作品再接着看。首版不模拟一边完整沉浸、一边外出办事。
5. **一次时间只记一次。** 复用正常回合的世界时间与事件顺序，不让播放和普通时间指令各加一遍。界面停留、模型生成耗时和读档不推动游戏时间。
6. **失败如实保留。** 复用现有检查点与草稿恢复。扩写失败不冒充已看完，重试沿用原作品和当前位置；已经成功的交易不重复执行。

店内按次开始前说清本次价格和使用方式，主动退出后再次购买按次服务正常收费；自己持有作品的重看不重复买片。临时中断和争议按已约定条件与现有交易处理，不在首版扩成专门的售后工作流。

## 六、烟火气与人物来往

同看先作为普通人物场景处理。谁在场、谁参与体验、谁摘下设备、谁离开，按正文实际发生的事和既有知情规则记录，不建立多人同步协议或秒级参与区间。

- 店员记得实际买卖、推荐和玩家当面说过的话，不自动知道私人体验与没有说出的评价。
- 同行者只知道实际体验与听见的内容；摘下设备但仍在房间里的人，可以听见现场聊天。
- 回访能接上同一店员、作者、系列和旧话题；已有目录不因开关面板重新随机。
- 购买不自动证明偏好，消费不自动兑换信任、恋爱或好感奖励。
- 正常娱乐可以舒服地结束；伤害、神经异常和纠纷需要具体前因。
- 看完可以回家、睡觉、吃饭或再聊几句，不强加片后任务、秘密或危机。

先做好几部能记住的作品、一个愿意再去的店和几次能接上的交流，再扩充内容。

## 七、调查与界面边界

现有三层调查编辑器继续处理专门的调查材料。普通娱乐使用正文体验，不强制生成关键线索、正确答案和委托结局。

普通体验与调查材料保持清楚的用途区分；普通正文不注入调查答案和幕后真相。首版不借此重构整套调查玩法，也不搭建通用媒体平台。

沿用现有正文、商店、交互入口与界面风格。首版通过自由输入和现有建议选项承接操作，不新增复杂播放器、完整媒体库面板或全局布局改造。

以下从首版删除，只有出现实际需求时再单独评估：逐秒游标、独立双时钟、观看区间统计、多人同步协议、通用版本/授权体系、设备预约与占用管理、专门退款流程、租赁订阅、创作产业和全城经营模拟。

## 八、实施顺序与验收

### 实施顺序

1. 在现有超梦功能内补充普通作品资料与轻量当前体验记录；调查编辑器保留原用途。
2. 将普通体验接入现有正文、交易、物品、世界时间和恢复流程，完成开始、继续、略写看完、退出与重看。
3. 补少量不同题材的作品和店员推荐，把同看、评价与回访接到人物和场景记忆。

制作阶段不做旧格式兼容与双轨兜底；当前版本的保存载入仍须可靠。每一步完成执行 Git，有文件变化立即单独提交。实施时不主动运行单元、集成或浏览器测试，只保留必要的静态类型和代码规范检查，交由用户体验验收。

### 人工验收标准

- [ ] 没有委托，也能选片、体验、离开，完整度不依赖片后事件。
- [ ] 同一作品重看内容一致，片中人物不被玩家改写，定稿片段不因重试重抽。
- [ ] 正常观看、略写看完和中途退出的钱与时间对得上，不重复收费或加时。
- [ ] 中途保存、读档或生成失败后，能接着原作品与当前位置继续。
- [ ] 与朋友一起看的交流能在之后提起，未参与的内容不会自动共享。
- [ ] 再去同一家店，能接上已有作品、店员和上次的话题。
- [ ] 文风继续由预设负责，普通体验不强加伤害、奖励、任务或调查题。

真实内容与人物交流是否好看，由用户单独体验判断；状态正确不能替代文字质量。
