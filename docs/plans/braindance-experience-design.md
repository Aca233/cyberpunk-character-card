# 超梦体验与日常消费策划案

状态：待实施；本案只确定设计与实施顺序，不表示功能已经完成。

日期：2026-11-19

范围：夜之城自由文字沙盘中的超梦作品、消费、播放、同步同看与调查接入。芯片通用改造、玩偶服务、完整创作产业另案处理。

## 一、定位与体验目标

核心定位：**固定作品＋可控制的沉浸体验＋看完后的生活延续。**

玩家没有委托时，也能去店里挑片、在家重看、与朋友同步体验，或者只和店员聊聊某个系列。一次普通消费能够完整、平静地结束，留下作品、时间、钱款和实际来往，不自动派生委托、危机或关系奖励。

超梦的交互围绕借用录制者的感知展开。玩家决定怎样观看、关注哪里、何时暂停和退出；同一版本中已经录下的人物、事件与感知材料保持固定。影片中的人物不会因为玩家对播放器讲话而改变行动。

### 设计原则

1. **作品可以重逢。** 名称、作者、录制者、系列、版本与内容有稳定身份；重看、推荐和讨论指向同一份作品。
2. **普通娱乐本身成立。** 旅行、演出、运动、职业体验、成人作品和私人纪念均可存在，调查是有条件开放的用途。
3. **玩家控制权明确。** 录制者的情绪是外来记录输入，不替玩家决定喜恶、认同、爱意或后续行动；购买也不自动证明偏好。
4. **世界事实持续。** 付钱、取得载体、已看范围、书签、同行者和当场交流进入正常存档，切场不会重置。
5. **文笔交给预设。** 内置规则只管理事实、视角、权限、记录范围、进度与输出协议；不加入固定写作示例、感官配额或统一文风。
6. **消费有实际条件。** 播放受作品使用资格、设备、地点和现有约定约束，不增设好感分数、声望等级或每日次数门槛。

成人作品作为成年角色的成人娱乐品类进入同一作品、交易与播放机制。本案只规定其商品身份、录制与分享权限、体验会话和关系边界，不编写露骨样文，也不为该品类另造一套数值玩法。

## 三、首版范围

### 首版必须完成

- 固定作品与版本、简介、章节、录制视角与可感知范围。
- 两种消费路径：店内按次体验；购买具体作品副本后自备设备播放。
- 独自体验，以及同一现场、同一播放进度的同步同看。
- 继续、暂停、恢复、回看、章节定位、关注已有细节、省略叙述后正常看完、退出。
- 片内秒级游标与游戏世界分钟时钟的明确换算。
- 已看区间、书签、收藏与玩家明确表达的评价。
- 固定经营者与作品目录、同日目录稳定、回访时召回有关买卖与交流。
- 购买与开场结算、会话进度、检查点、保存载入与失败恢复。
- 同一作品可选进入既有三层调查用途，作品、播放和调查进度彼此独立。

### 后续扩展

以下不阻塞首版：限时租赁、订阅会员、远程异步同看、任意倍率快进、完整录制与剪辑生产、作品转售产业、创作者经营、自动推荐算法、全城店铺与员工排班模拟。

首版的“快进到某段”用章节定位表达，不计算连续倍率播放。作品可以先按段落组织，段落数按内容需要确定，不把固定段数当成叙事节奏要求。

## 四、玩家流程

### 4.1 店内按次体验

1. 到达实际经营地点，取得该店已经确立的作品目录与可用设备信息。
2. 查看简介、时长、版本、设备条件与本次价格；简介和预览不默认包含整片内容。
3. 玩家明确选择后，核对具体作品版本、经营者、设备可用性和实际交易授权。
4. 同一成交事件完成扣款、报价使用、一次体验资格和会话建立；任一环节失败则整件事撤销。
5. 玩家开始播放，按实际操作推进片内进度和游戏时间。
6. 完成或主动退出，释放设备，保存观看记录与实际交流，允许直接离开。

首版按次费用对应一部指定版本、一次到店会话。暂停与回看属于原会话；主动结束后再次开场属于新的一次消费。条款在付款前展示，不在玩家提前退出时临时补规则。

暂停保留设备占用，约定营业或服务截止仍会随游戏时间到来。店方故障导致中断时保留原订单，可恢复时不重新收费；确定无法履约时退回本次按次费用并终止会话，已发生的时间与观看经历保留。玩家主动退出默认不退按次费；不同约定必须在成交前明确记录。

若店内有已告知的服务截止时间，成交前写入本次条款。预计正常观看会超过截止时，须先说明不足以看完全片，由玩家选择接受本次窗口或不购买，不能按可完整观看作出报价。到截止时仅播放至实际可用时刻，按计划内终止结束本次会话、释放设备并保存书签；退款依原条款处理，不自动按店方故障全退。暂停聊天也会消耗该营业窗口，恢复时再次核对截止条件。

### 4.2 购买作品后自播

1. 成交取得一份具体版本的实物载体或可验证的本地存储副本。
2. 作品资料引用实际载体或副本身份；当前持有与已看内容分开记录。
3. 有可访问副本、可用设备和合适地点时，可以建立不重复收片费的自播会话。
4. 退出保存书签；下次可从书签、已知章节或开头继续。

若实物被交出、遗失或存储副本确实被删除，重新核对当下访问来源；不凭一条“买过”记录无限生成新副本。角色已经获得的记忆不会随载体转移而消失。首版不建立全套版权执法模拟，访问资格表示世界中实际可访问的材料与许可。

### 4.3 同步同看

首版限同一现场使用同一播放进度，不支持每位同行者独立拖动一条远程时间轴。设备与消费条款须允许相应参与人数；购买者不能替另一个人作出参与决定。

首版共享游标由玩家操作，其他参与者可以按本人意愿加入、暂停或退出。加入从当前进度开始，不补记之前的体验。现实对话使整组同步播放暂停，恢复后再共同推进。

每名参与者单独保存播放参与区间与现实在场范围。摘下设备但仍在房间里的人，不获得后续片内体验，仍可能听见现场谈话；真正离开现场后才不获得后续现场交流。共同观看推进一次世界时间，不能按人数重复加时。

共同经历关联到已提交的同一次播放操作及当时参与者，不能只比较合并后的片内区间。例如甲和乙分别在两次重播时看过同一段，不等于两人曾经共同观看该段。

## 五、作品如何确立与重看

### 5.1 身份与版本

- 作者、剪辑者与录制者可以是不同的人；未与玩家互动的演职人员先保留轻量身份，不强制给每个人建立完整 NPC 卡。
- 同一作品的广告版、删减版、重剪版采用独立 `editionId`，可共享 `workId` 和系列身份。
- 同一版本不能因再次进店、切场、玩家追问或重开游戏而重新抽样。
- 新店可以按地点与经营定位建立目录；一旦形成世界事实就保存，之后上新、下架与改价需要对应的变化记录。

### 5.2 固定内容与按需展开

上架或首次确立作品时，固定标题、版本、录制者、时长、章节顺序、主要事件、记录来源和感知边界。普通娱乐在首次播放相关片段前补齐需要展开的已录细节，定稿后保存；已经呈现的事实和原文不得随重试改写。

关注细节只能展开已有材料能够支持的信息。若材料中没有记录，就明确没有更多可辨信息；不能为了满足问题即兴补出姓名、密谋或其他关键事实。调查版的证据、误导、可观察细节与真相必须在进入调查前一次确定。

重看已有片段可直接回放定稿原文。改变关注点时，可以补充原记录内尚未展示的细节；新增事实必须有来源并成为该版本持续事实，不能与旧内容矛盾。涉及调查判断的细节只能从预先冻结材料中取。

作品片段缓存只包含录制内的固定内容。现场朋友的插话、玩家评论、摘下设备后的动作与当次环境保存在会话/正文记录中，不混入可复用的作品原文；重播作品不能把上次现场交流当成又发生了一次。

片中可能存在表演、虚构设定、剪辑与宣传包装。观众知道“作品呈现了什么”，不自动知道录制者的真实私生活，也不把表演情节直接记成现实发生的案件。

### 5.3 视角与感知

- 玩家接收的内容受录制者当时的感知、源材料与剪辑版本限制。
- 录制者的感受、情绪与玩家自己的判断分开；不把记录输入直接写成人格改变、恋爱或偏好。
- 调节输入强度以既定设备能力为依据。正常体验无须每次掷骰、产生伤势或扣除人性数值。
- 异常体验造成的具体后果须有作品、设备、身体或实际操作前因，沿用已有伤势与神经事实系统处理，不增加常驻“爽度”“成瘾值”或通用增益条。

## 六、播放会话与操作规则

### 6.1 会话状态

`准备完成 → 进行中 ↔ 已暂停 → 已完成 / 主动结束`

设备故障、断链、被迫离开播放地点等实际原因使会话进入 `已中断`。原因解除且原资格仍可用时恢复；否则结束或按原条款处理退款。关闭面板、浏览历史、电脑实际闲置不自动结束或推进会话。

首版只允许玩家同时沉浸于一个活动播放会话。可以保存多部作品的书签与调查档案；未做完一项调查不会阻止体验另一部无关作品。只有真实设备占用或现场条件能造成阻挡。

### 6.2 操作表

| 操作 | 作品进度 | 游戏时间与记录 |
| --- | --- | --- |
| 查看简介、菜单、已有文字记录 | 不变 | 不耗时，不自动增加已看范围 |
| 继续体验 | 推进至本次确定的位置 | 按正常播放时间推进；仅本次实际播放区间进入体验记录 |
| 关注当前细节 | 在当前可访问材料中展开 | 查阅已有记录不额外耗时；若实际重播则按重播区间计时 |
| 暂停 | 停在当前位置 | 暂停按钮本身不耗时；现实中的聊天、等待照常计时 |
| 恢复 | 从当前位置继续 | 先核对设备、地点、原会话与资格，再按播放时间推进 |
| 定位到某章、倒回某处 | 只改变游标 | 首版定位按钮不耗时；跳过的区间不算体验过 |
| 重播一段 | 从定位处实际重新播放 | 世界时间继续向前；已看区间去重，累计播放时间照常增加 |
| 省略叙述后正常看完 | 正常播放到结尾 | 消耗正常剩余播放时间，剩余区间记为实际体验；摘要不得虚构新交流或偏好 |
| 主动退出 | 停止本次播放 | 只保留已发生时间与内容，保存书签，释放设备，按约定结算 |

片尾到达表示本次播放结束；如果之前跳过章节，历史应写“播放至片尾、部分片段未体验”，不能伪报整片完整体验。

实际与现场人物交谈时，首版先暂停沉浸播放，再处理现实对话；讨论后由玩家继续。影片中的台词和现场人的台词保留不同来源。

### 6.3 正文与操作的配合

新片段或新的合理关注点由模型按既定材料展开；定稿原文回放与菜单操作可以直接读取，不要求重复调用。普通段落不强制出现选项，玩家可用自由文字打断、提问或继续。

模型不能根据一次“继续”自行播放完整部作品、替玩家消费另一部片，或自行安排片后亲密关系。一次播放计划的起止范围在展开前确定，默认前进到下一个有意义的停留点；玩家明确要求正常看完时才处理剩余全片。

## 七、双时钟与长时间操作

### 7.1 两套量分别保存

- `cursorSec`：当前片内位置，用整数秒表示，可以前进或后退。
- `playedRanges`：确实体验过的区间集合，合并重叠范围；跳段不填入其中。
- `playbackElapsedSec`：累计实际播放耗时，重播重复累计；不包含暂停后的现实聊天。
- `settledPlaybackMinutes`：已由播放会话结算到游戏时钟的分钟数。

游戏世界继续使用现有整数分钟，不为超梦另建一套世界日期，也不使用电脑墙钟、流式输出速度或页面停留时间。

正常播放换算：

```text
本次累计应计分钟 = ceil(playbackElapsedSec / 60)
本次播放增加分钟 = 本次累计应计分钟 - settledPlaybackMinutes
```

不足一分钟按同一会话累计向上取整；分十次重播几秒不会每次额外扣一分钟。该换算有至多不足一分钟的显示精度差异，属于首版分钟时钟的明确抽象。

暂停聊天走普通世界时间，不进入上述累计；恢复时只计算新增播放的分钟差额。同一事件的播放耗时由播放结算唯一负责，不能再被抽取的 `world.time` 重复追加。混合行动按先后拆分事实事件，统一推进现有游戏时钟。

### 7.2 长时间播放与打断

正常看完会让营业时间、既有约定和其他有前因的世界变化照常经过。任务或约定到期本身不强制停止影片。

只有已经具备原因、角色实际能感知且确会中断体验的现场事件才打断。若已有明确打断时刻，本次播放计划只推进到该时刻，剩余部分保留；不得先记完整片，再补写中途摘下设备。

本次条款中已确定的店内服务截止属于计划内终止，同样限制可推进范围；这与无关任务到期不同。到时结束占用与本次按次资格，不自动完成未看内容，也不默认产生店方故障退款。

设备损坏、现场离开、参与者离开等变化按实际发生顺序结算。暂停或中断不会自动播放剩余部分，也不会因恢复而把中间时间重复计费。

## 八、最小持久数据

以下为建议结构，实施时与现有类型合并；不要求把同义字段重复存在多个系统。

| 数据 | 最少字段与责任 |
| --- | --- |
| 作品版本 | `workId`、`editionId`、标题、作者/录制者引用、系列、品类、版本说明、时长、简介、章节与固定感知材料、可用记录层 |
| 副本或访问来源 | `accessId`、`editionId`、实际载体/存储副本引用或店内订单引用、当前提供者、允许用途与同看范围；归属沿用实际物件记录 |
| 播放会话 | `sessionId`、会话修订号、作品版本与访问来源、地点、设备、提供者、消费条款/服务截止、状态、游标、已看区间、累计播放秒数与已结算分钟、书签、播放参与区间、现实在场引用、操作回执引用 |
| 观看经历 | 对应会话与已提交播放操作、实际时间与地点、版本、观看范围、当次参与者、玩家明确的收藏/书签/评价、实际交流引用 |
| 调查档案（可选） | 原始版本引用、冻结证据与事实、已扫描条目、玩家的阶段判断与最终结论；独立于普通观看记录 |

作品只保存一份；会话、访问和历史引用它，不在每条历史中复制整部材料。观看经历不能仅靠 FIFO 删除最近之外的内容；保留作品与有关人物的稳定关联、书签和重要原话，普通重复访问可以合并。

## 九、交易、保存与失败恢复

### 9.1 报价与付款

- 报价目标绑定具体作品版本与商品类型，明确是副本还是店内按次服务；不能仅以笼统“超梦服务”在成交时换片。
- 复用 `commerce.offer` 和现有玩家交易授权；询价、预览、比较与玩家单方面出价均不算接受。
- 一笔成交的扣款、消耗报价、交付副本或建立按次会话、占用设备放在同一因果事件，全部成功或撤销。
- 现有内核不是任意多条顶层指令天然一起回滚；实施需复用现有事件事务或单条指令的内部连锁，不能靠指令相邻假定原子性。
- 会话建立、播放操作与退款均有稳定事件/操作身份。请求重试、抽取重复和载入恢复不会再次收费或重复退款。

每次修改会话同时携带稳定操作号与期望会话修订号，复用既有请求回执、事件记录和版本核对。已成功的同一操作返回原结果；旧操作落后于当前修订且无法取得原回执时拒绝执行，不当作新操作。不能只比较“最后一个操作号”，以免出现 A 成功、B 成功、旧 A 再到达后重复加时。无需另造第二套事件日志，但保存载入后去重与过期拒绝仍须成立。

### 9.2 播放检查点

采用“确定本次计划 → 按材料展开正文 → 核对并提交本次事件”的顺序。

计划至少绑定操作号、作品版本、起止游标、应计时间与允许揭示的材料。生成失败或格式修复时复用原计划，不重新选片、不重抽作品、不擅自向后推进。

开始会话已经成功支付的事实与后续播放分别保存。首段扩写失败保留已建立会话；重试不会重新付开场费。未成功提交的播放不增加进度、时间或已看事实；需要取消时只撤销待处理计划，再按既有会话条款处理退出。

流式未定稿或与账目冲突的正文不进入后续历史、人物记忆、场景摘要与已知事实。沿用现有检查点、事件失败隔离和按账目改写入口，不另造第二套恢复日志。

### 9.3 载入与恢复核对

读档保留原作品版本、会话阶段、收费状态、进度和已知范围。继续前重查实际访问来源、当前地点、设备状态与服务条件；核对失败说明具体原因，不悄悄删除作品或把剩余片段标成完成。

制作阶段直接采用新状态结构，不保留旧 `active.recording` 存档兼容层、双轨格式或旧接口兜底。当前格式自身的保存、载入与失败恢复必须可靠。

## 十、日常延续与知情边界

### 10.1 熟客与作品文化

店员可以记得实际成交、推荐和玩家当面说过的话。只看得到交易记录的人，不自动知道玩家在设备内的体验与私人评价。

回访优先召回与当前店铺、店员、系列、作者和同行者有关的几条具体来往。例如上次抱怨广告、等某个系列续作、答应与朋友一起看。重复购买不自动增加信任、恋爱关系或任何固定奖励。

作者、系列和已有作品持续存在，上新与下架可以形成轻量生活变化。目录和价格不会在每次打开面板时刷新；首版仅为实际涉及的场所保存必要记录，不模拟全城每个顾客。

### 10.2 记忆来源

以下内容分别记录，不互相冒充：

1. 作品呈现的内容，以及其版本与片段来源。
2. 玩家角色实际体验的范围。
3. 玩家对作品主动表达的评价。
4. 同行者实际体验和听到的现场交流。
5. 调查扫描取得的材料，以及尚未证实的判断。

作品中的演员或录制者不会因为玩家看片而自动与玩家相识；“在作品里见过”不触发真实见面或共同经历。未看内容不会因为模型知道全片就进入角色知识。

普通结束记录消费和交流即可。睡觉、回家、转去吃饭、再选一部都可以成立，不要求以悬念或委托收尾。

## 十一、调查接入

普通作品可以没有任何调查字段。商业剪辑版不会因为玩家切换模式凭空长出原始视频、音频或红外材料；进入分析先核对源材料、设备能力和实际访问范围。

调查与播放引用同一作品版本，但各自保存进度。切换用途不重建作品、不清除扫描发现，也不无故再次收取已支付的作品费用；新增设备或专业服务费用需要独立报价与玩家接受。

首版保留现有三层编辑器、标点与冻结结论的专项交互，不在本案加入自由推理自动判题器。既有编辑器内定位与标点零游戏耗时暂作为明确的分析界面抽象；实际接入、现场聊天和其他行动仍按既有时间规则处理。分析发现进入知识记录，不冒充沉浸体验的观看覆盖。

调查内容必须做到：扫描给出可观察事实，最终结论有相应证据支持；资料收件人不能仅凭收件身份就被认定为幕后雇主。信息不足时只得出较窄的判断，后续通过实际调查查证。错误判断的后果按实际行动发展，不在提示词中一概要求立即结束整单委托。

普通播放上下文不携带正确答案、未扫描结果和幕后真相。调查专项所需秘密按阶段提供，继续使用公开投影隔离；前端和正文都不能依靠“已经传给模型/浏览器，只要求别说”来替代权限边界。

## 十二、提示词与界面接入

### 提示词

只在选片、播放、回看、讨论相关作品或调查时加载有关规则。当前片段、现实场景、同行者、已知材料与本次确定进度是正文的主要输入；其他作品目录按当前商店或明确检索范围选取。

启用预设后，文风、篇幅、节奏、修辞与描写方式遵循预设。人物卡已有口吻继续生效，不加入内置通用人物腔调。优先保证事实连贯、作品辨识度与人物交流质量；必要材料不能为了省调用而删除。

### 界面

沿用现有正文、商店/交互入口和神经界面风格。普通体验只增加必要的作品信息、播放状态与控制，具体低层视觉设计在实施时另行对齐相邻控件；本案不授权重做整体界面、布局、样式或展开面板。

- 作品信息：简介、版本、作者/录制者、时长、实际商品条件与已知章节。
- 会话控制：继续、暂停/恢复、章节定位、正常看完并略写、退出；自由文字同样可用。
- 收藏与历史：查看已有材料不等同于角色实际重播，不额外收费或耗时。
- 调查：继续使用现有编辑器；普通体验不弹出关键线索进度与结论题。
- 任务追踪：普通在播状态可在相关交互处显示，不登记为必须完成的任务。

## 十三、首批内容与无任务场景

首批以能被记住的少量作品、作者和系列为目标，覆盖普通娱乐、成人作品、私人纪念，并用少量原始记录验证调查接入。数量属于制作规模，不是 schema 限制或写作配额。

建议先做 6—10 个作品版本，至少有能再次出现的系列/作者，以及同一作品两个版本的可见差异。以下均为本作拟制题材，不作为原作事实：

| 作品方向 | 日常体验重点 | 持续联系 |
| --- | --- | --- |
| 海岸旅行片 | 不同剪辑、广告与调谐质量 | 店员后续推荐同一作者的新作 |
| 地库现场演出系列 | 一场具体演出、演出者与收音特点 | 朋友谈论其中一首歌，店里上架下一场 |
| 运动或职业体验 | 录制者具体身份与实际感知范围 | 玩家可重看某段，不自动学会职业技能 |
| 成人商业系列 | 演职人员、作者、版本与实际商品特点 | 收藏、熟客推荐、与伴侣共同选片 |
| 自愿分享的私人纪念 | 具体来源、分享范围与私人意义 | 通过真实交流逐渐增加双方了解 |
| 原始记录 | 有限视角与可查证材料 | 可选进入调查，不要求绑定委托 |

### 场景 A：下班后进店

玩家选择一部带广告版本，体验十分钟后退出，并当面对店员说广告太多。系统保留一次消费、十分钟播放、已看范围和这句实际评价；再次到店可以推荐无广告版本。玩家直接回家，场景完整结束。

### 场景 B：与朋友同看

两人播放已购买作品，中途暂停聊天；朋友提前离开，玩家随后选择略写正常看完。世界时间只推进一次，参与者区间分别保存；朋友次日只记得共同体验部分与实际听到的聊天。

### 场景 C：在家收藏重看

玩家从一部成人或旅行作品的书签重播一段，之后摘下设备去睡觉。作品内容不变，不重复收购片费，重播正确耗时；没有自动关系奖励、伤害或新任务。

这些场景的题材和措辞不作为内置文风样例；验收关注实际状态与正文是否自然接续。

## 十四、实施拆分与源码落点

| 步骤 | 内容 | 主要落点 | 完成条件 |
| --- | --- | --- | --- |
| 1. 作品与访问 | 分离作品版本、载体/副本引用、按次访问与可选调查数据 | `core/systems/braindance/schema.ts`、`content/src/braindance.ts`、既有物品与商家目录 | 同一作品可长期保存、重复访问；普通作品无需调查字段 |
| 2. 会话与时间 | 播放计划、状态、游标、区间、累计耗时、检查点与恢复 | `braindance/apply.ts`、`actions.ts`、现有内核事件与时钟 | 正常观看、暂停、定位、回看、略写看完、退出均有确定结果 |
| 3. 消费接入 | 具体版本报价、副本交付、按次开场、退款与设备占用 | `commerce/`、`inventory/trade.ts`、现有交易授权与事件事务 | 一次交易只结算一次；失败无半笔交易 |
| 4. 正文与公开投影 | 当前可体验材料、已知范围、公开信息、必要控制入口 | `braindance/prompt.ts`、`view.ts`、`events.ts`、`interactions.ts`、前端现有入口 | 未看/未扫描/幕后材料不泄露；界面与正文状态一致 |
| 5. 同看与生活记忆 | 参与者区间、真实交流、作品关联召回、目录延续 | 既有 `npc/`、`memory/`、商家上下文与会话数据 | 回访能接话；商业记录、私人体验与共同交流有权限边界 |
| 6. 调查与内容整理 | 现有编辑器改为引用固定版本，清理普通体验的任务化耦合 | `braindance/objectives.ts`、调查应用、内容示例与 `BraindanceEditor.tsx` 的必要接线 | 原始材料可分析；普通消费能平静结束；示例证据与答案相符 |

表中 `core/` 均指 `packages/core/src/`，前端沿用 `apps/web/src/features/story/`。实施中按真实依赖补充声明，避免系统之间循环读取；正文模型不能直接覆盖核心状态。

每完成一步执行 Git；有文件变化立即单独提交，没有变化也执行 `git status`。只修改当步范围，保留工作区其他改动。旧格式与废弃分支按当前设计清理，不为制作期历史兼容保留双轨实现。

## 十五、验收标准

以下为交付给用户的人工验收清单。遵守项目约定，实施代理不主动运行单元、集成或浏览器测试；必要时仅做类型与代码规范静态检查。策划文档本身只做内容、链接与 Git 差异检查。

### 状态与结算

- [ ] 同一版本的事件、人物、视角和定稿材料在重看、读档和重试后保持一致。
- [ ] 购买、已看、片尾到达、完整观看与调查发现彼此区分；跳段不会伪造已看内容。
- [ ] 店内一次消费只扣一次费，自播重看不重复购片；设备/余额/资格不满足时无半笔交易。
- [ ] 正常播放、暂停聊天、倒带重播、定位与略写看完的时间结果符合双时钟规则。
- [ ] 短片段重复操作按会话累计换算分钟，不因每次独立取整而多扣时间。
- [ ] 暂停、关闭面板、主动退出、中断与读档恢复的占用和收费结果明确。
- [ ] 已告知的服务截止使本次会话按约定终止并释放设备；暂停不能无限延长店内资格。
- [ ] 同步同看只推进一次世界时间，各参与者仅保留自己实际经历的区间与交流。
- [ ] 摘下设备、离开现场和后来加入有不同知情结果；不同批次分别看过不误记为共同观看。
- [ ] A、B 成功后再次收到旧 A，不会重复加时、扣款或退款；载入后同样成立。
- [ ] 正文生成失败或结算部分失败不重复付费、不重复加时、不污染正式记忆。

### 正文与生活质量

- [ ] 普通作品能仅凭消费、体验、聊天与离开完整收场，不强加任务或危机。
- [ ] 作品有可以再次辨认的作者、系列和版本特点，内容质量单独由用户阅读判断。
- [ ] 三次造访可以接续同一店员、作品与来往，不每次重置成陌生人。
- [ ] 录制者的情绪输入不会替玩家决定喜恶，购买和观看不自动增加信任或恋爱。
- [ ] 影片中的人物不会回应播放器外的提问，也不会因为看片而自动成为玩家的现实熟人。
- [ ] 重播作品不会重演上次的现实聊天，作品片段缓存与会话交流保持分离。
- [ ] 现实交流、私人体验、交易记录、调查发现与幕后真相保持来源和知情边界。
- [ ] 启用写作预设时没有叠加内置文风、感官配额或固定段落写法。
- [ ] 普通体验与现有界面协调，调查编辑器仍可使用，整体布局和样式未被借机重做。

结构与静态检查只证明实现和状态接线的一部分正确，不能代替玩家对真实体验、人物交流与文字质量的验收。
