# 创意工坊 Steam 化重构计划（广场 + 订阅 + 三合一发布）

> 状态：已完成（2026-11-26）

## 背景与痛点

旧版创意工坊采用左右 50/50 固定分栏，左栏长期空置，右栏混塞「社区 / 导入 / 检视 / 表单编辑」4 个开发向标签，强迫玩家在工坊页内手填底层结构表单，与玩家实际体验严重割裂。

## 目标架构（Steam 创意工坊形态）

1. **主界面极简两页签（全屏宽版，完整适配 4 套外壳动态主题）**
   - **社区广场（默认）**：全屏搜索 + 分类胶囊（全部 / 角色卡 / 义体 / 武器物品 / 人物人脉 / 主板模块 / 超梦芯片）+ 排序 + 2–3 列大卡片墙（16:9 封面图或赛博排版封面、下载数、条目摘要、一键「订阅安装」）；点击卡片弹出详情弹窗，可预览全部条目、一键将包内角色卡导入本地角色档案、下载/更新、管理下架。
   - **我的订阅**：集中管理本机已安装的内容包（启停开关、查看详情、一键发布/更新云端、导出 JSON、卸载）。
2. **右上角唯一主入口「＋ 发布作品」三合一弹窗**
   - **从本地打包**：直接勾选角色工作台里已保存的**角色卡**、**自创义体**、**自创出身/特质/缺陷模块**，或直接选用已有本地内容包，配可选 16:9 封面图一键发布到社区或保存本地。
   - **AI 一句话生成**：输入想法 → 调用已配置辅助模型（`POST /api/workshop/generate`）生成合规内容包并做规范化校验 → 预览满意即可直接本地启用或带封面图发布到社区。
   - **上传 JSON 文件**：拖入/选择/粘贴 `.json` 内容包 → 校验预览 → 直接装本地或发布到社区。
3. **协议扩展**
   - `WorkshopPackSchema` 新增 `characters: CharacterCardSchema[]`（最多 20 张），支持玩家分享与一键导入完整角色卡；同步更新社区后端 `functions/api/community-workshop/core.ts` 与 `d1.ts` 分类统计及筛选。
