> 状态：已完成

## 目标

彻底清理义体界面中残留的旧版本逻辑（左侧假 `100/100` 人性数值温度计、暗示上限的固定空格子、悬停挡格子的浮窗、诊所缺失互斥与负荷预览），全面升级三处核心义体界面：
1. **人体拓扑组件（`CyberDoll`）**：去掉过时数字人性条，实现 50% 严格居中对称；未装部位只显示 1 个带解剖图标的空挂载格，已装部位动态展示最多 3 格 + `+N` 溢出格，永不撑爆或重叠，并支持直接点击部位标题切换。
2. **局内义体页（`CyberwarePage`）**：升级为顶部「全身义体与神经遥测栏」+ 左栏居中解剖图 + 右栏常驻「当前部位详情」面板（去掉冗余的「全身清单」页签），清晰呈现负荷档位、双中枢/FBC 状态、互斥组、行为芯片与损毁状态。
3. **局内义体医生诊所（`Ripperdoc`）**：接入物理互斥组标签、负荷短标、「零负荷生活/感官」快筛、部位已装计数微标与术后负荷变化预警（双中枢并行 / 全身义体化 / 跃升高压重改）。
4. **创角义体页（`CharacterCreator` & `CyberwareShelf`）**：修复居中偏移与 `[data-tone="bad"]` 警告色，新增「零负荷生活向 / 实战重装 / 自创」快筛与当前部位已装快捷卸除条。
