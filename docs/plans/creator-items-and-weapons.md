# 角色创建行装升级：取消武器限制、开放开局物品与自建武器/物品

> 状态：已完成（2026-11-26）

## 目标

1. **取消开局武器限制**：移除最多 2 把与禁止不朽/稀有度限制，全目录武器（含不朽、全部稀有度、工坊与自创）均可自由选配；前 3 把自动进快捷槽，其余自动入背包。
2. **开放开局随身物品**：Step 03 顶栏拆分为四个同级直达标签（`义体装配` / `随身武器` / `随身物品` / `专属座驾`），避免物品藏在 100 把武器列表下方；启动资金档位与自定义欧元移入右侧常驻 `NC // LIVE DOSSIER` 竖栏随时直调；全目录非武器物品（治疗品、手雷、服装、改装件、消耗品、杂物）支持搜索、分类筛选与数量增减（1–20）。
3. **支持自建武器与物品**：在创角界面原地支持「＋ 自建武器 / ＋ 自建物品」（[CustomItemForm.tsx](file:///c:/cyberpunk-character-card/apps/web/src/features/characters/CustomItemForm.tsx)），支持存入本机自定义池（`cp.workshop.localItems`）、编辑/删除、自包含快照随角色卡保存与建档进局（`board.kit.customItems`），并同步接入创意工坊「从本地打包发布」。
4. **修正创角工作台比例**：收窄左侧全息人体剪影（`clamp(188px, 21%, 236px)`）并用容器单位等比撑满高度消除黑底空洞；拉满 `NEURAL LOAD` 神经承载进度条；优化页面安全留白与右侧 `NC // LIVE DOSSIER` 宽度比例，让主编辑舞台与义体货架更舒展。
