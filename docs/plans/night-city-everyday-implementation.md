## 可以从哪里开始

- 歌舞伎市场：阿岚经营 `sleeve-corner` 芯片小铺，提供固定片目、维修资料、日常便条、成年作者刊物、资料读写器、空白载体和便携超梦头戴机。可以只翻标签、问价、聊天，之后再决定买或不买。
- 日本街：乔是未安装行为芯片的成年真人从业者；诺亚是实际安装行为芯片的成年真人。两人有各自的工作与生活，不共享客户记录。可以闲聊、问清范围、接受服务或正常离开。
- 超梦目录：《摊灯熄灭以前》《雨停后的屋顶》《返场第三首》，另有《后勤通道的三分钟》短材料。没有委托也可以选普通娱乐，消费本身不触发任务。

这些场所沿用已有地图地点和自由输入。默认沙盘开局包含三位新增人物；其他场景若尚无人物卡，相关地点上下文会提供同一份固定资料，依正常出场流程建卡。

## 已接入的行为

| 内容 | 实际实现 |
| --- | --- |
| 芯片实物 | 购买模板芯片时物化独立载体；同内容的不同副本各有归属和来源，取得不会自动阅读 |
| 资料使用 | `chip` 的 define/read/unlock/copy/use 接入现有设备、库存和黑客事实；复制需要实际读写器和空白载体 |
| 原文档案 | 稳定内容 ID 与分段 ID，定稿不可覆盖；取消 60 条淘汰，按当前关联召回；阅读页分页，界面已浏览不等于角色刚读取 |
| 转交与借用 | 继续使用现有物品转交、归属和承诺记忆；交出原件不清空角色已经获得的知识 |
| 成人服务 | `adult-service` 先明确主体、范围、价格、总时长、记录许可和中止条件；玩家接受后由既有交易统一结算 |
| 服务进度 | 继续、暂停、恢复、正常结束或中止使用累计实际分钟；略写正常结束补足剩余时间，不再次收费 |
| 行为芯片 | 实际安装、本人授权、当前接管模式、真实设备摘要及本人查阅分别记录；接管迎合不自动成为本人感情 |
| 人物知情 | 本人亲历、后来被告知、查阅设备摘要区分来源；日志不自动成为亲历，也不自动送给前台或其他人物 |
| 超梦体验 | 固定作品和段落，开始、逐段继续、暂停、恢复、略写看完、退出、重播及按历史位置重新接入 |
| 正文查证 | 仅具体追问、已见材料和实际设备共同支持的细节可以揭示；没有线索计数、固定答案或自动判整单失败 |
| 真实来源 | 自有载体与手边设备，或已付费店内服务；设备具有明确播放及分析能力，不能从宣传文案凭空获得红外数据 |
| 失败与重复 | 复用现有事务、检查点与保存载入；报价、付款、交付相互核对，累计分钟及回合内操作去重 |

已付款而尚未接入的超梦允许单独结束本次按次服务，不伪造播放或自动退款。实际已接入时由超梦退出一起保存当前位置。新的店内按次消费需新约定，自有作品重看不重复购片。

没有新增成人面板、播放器面板、文件管理器、满意度、技能奖励或恋爱消费门槛。文风继续由已启用的写作预设负责。

## 用户体验入口

以下是自由输入示例，按实际对话逐步进行，不是额外指令按钮：

1. “去歌舞伎市场看看阿岚的芯片小铺，先问问生活超梦和维修资料的价钱。”
2. 在明确报价并决定购买后，要求用实际持有的读写器读取维修便笺；之后买空白载体、复制，再借给认识的人。
3. 选一部店内超梦，确认条件后接入；分别试着暂停聊天、继续、略写看完，再主动提起片中某个具体细节。
4. “去日本街找乔，先问问她今天忙不忙。”可以只聊、改天再来，也可以在明确约定后消费。
5. 与诺亚确认本人愿意接受的范围，区分实际启用芯片、退出接管及后来查阅摘要；回访只接续本人真实知道的事。

重点关注：询价不扣款，重复操作不重复记账，正常娱乐能平静结束，回访不换人，未知内容不被提前知道。保存后再读档，检查固定原文、物品归属和当前进度能否接续。
