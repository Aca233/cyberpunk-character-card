## 一、三层人体结构：物理主位 + 有限功能区 + 零负担外观

彻底放弃旧的 10 个医药解剖槽和“无上限随便塞”，严格按人体常识分成三层：

### 1. 上层：8 个核心主位（一坑一物，换新即替换）

1. **躯体底盘**：原生血肉（默认） / 双子星拟真躯壳（Gemini FBC）/ 重装战甲躯壳（Dragoon FBC）
2. **网络接入仓**：1 套（也可装 **装植减缩器 Chrome Compressor**——放弃主驱/接入仓，专门大幅扩容神经承载）
3. **脊柱主驱**：1 套（斯安威斯坦 / 狂暴；允许与接入仓并存，但触发「双中枢并行」额外吃 `+12` 神经承载）
4. **主义眼**：1 对（双眼成对光学模组）
5. **左臂**：1 位（独立记录；单臂装配仅计 **60%** 承载，还原银手式单机械臂）
6. **右臂**：1 位（独立记录；提供一键「双臂同款」，同款双臂按 **100%** 计不扣双倍；左右异构混搭各计 **60%** 共 **120%**）
7. **腿部驱动**：1 对（二段跳 / 蓄力跳 / 全地形腿 / 液压腿等）
8. **表皮主甲**：1 套（皮下护甲 / 镀铬装甲皮 / 几丁质壳）

### 2. 中层：4 个功能扩展区（有限物理空间 + 少数显性互斥）

每个生理区域有真实人体空间上限（展示为 `已装/上限`，换装 FBC 全身机械躯壳后机舱空间扩大）：
- **脑机与神经**（上限 `4`）：RAM 协处理器、行为芯片、反应加速、克伦齐科夫、神经稳态阻尼等
- **面容与感官**（上限 `3`）：行为印记面甲、微表情测谎物镜、音频套件、嗅觉滤器、声带调制、超梦录制等
- **躯干与防护**（上限 `5`，FBC 底盘 `+2`）：心肺血泵、副心脏、免疫抑制泵、光学迷彩、防火/接地涂层、痛觉控制、钛骨/外骨骼承重架、走私腔等
- **手掌与足部**（上限 `4`，FBC 底盘 `+1`）：智能连接、弹道协同、精密/液压握持、近场干扰、静音猫爪、磁吸攀爬足、小腿暗格等

仅保留 5 组直觉 100% 明确的同类器官互斥（点击替换时直白提示“将替换「xxx」”，无隐藏暗规则）：
- 表皮隐匿层：`光学迷彩` vs `全息伪装覆膜`
- 痛觉覆写：`疼痛编辑器` vs `疼痛置换`
- 足底主改：`猞猁爪` vs `磁吸攀爬足`
- 承重外骨骼：`Σ 型军用外骨骼承重架` vs `工业负重脊柱架`
- 核心亲密义体：`午夜绅士` vs `午夜佳人`

### 3. 下层：1 个「外观与生活」区（零承载 · 不占功能格）

- 收录纯人设与日常生活义体：化学变色皮肤、电子光纹纹身、恒温仿生皮、时尚变色虹膜、颌骨微型暗格、合成费洛蒙、全身触觉增幅、多功能技师工具指、隐蔽式备用个人链路、核心亲密义体等。
- **不占神经承载、不挤占战斗功能空间**，仅按自身去重（核心亲密义体二选一），让生活流与人设党零阻力。

## 二、总闸门：三段式「神经承载」（真实防无限塞 + 盘活构筑取舍）

直接基于 187 件义体的真实神经负荷，并与预设角色和 74 位原作 NPC 完整校准：

| 躯体底盘                                   | 安全区（日常平稳）        | 超载红线区（允许硬装，真实代价） | 生理硬顶（装不下，直接拦截）     |
| ------------------------------------------ | ------------------------- | -------------------------------- | -------------------------------- |
| **原生血肉**（默认）                       | `0 – 38`                  | `39 – 50`                        | `50`                             |
| **原生血肉 + 装植减缩器**（弃主驱/接入仓） | `0 – 56`                  | `57 – 70`                        | `70`                             |
| **双子星拟真躯壳（Gemini FBC）**           | `0 – 48`（底盘自身占 15） | `49 – 70`                        | `70`（常驻高压维保与排异监控）   |
| **重装战甲躯壳（Dragoon FBC）**            | 无轻松安全区（常驻重压）  | `18 – 90`（底盘自身占 18）       | `90`（战争机器级，脱离常人社交） |
- **稳压/抗排异配件真正发挥作用**：
  - `装植减缩（Chrome Compressor）`：占用主控位（不能与接入仓/脊柱主驱同装），把血肉承载上限从 `50` 扩至 `70`，成就“纯被动重装流”。
  - `免疫抑制自动泵` / `情绪稳态阻尼器`：不突破硬顶，但把**安全线抬高 `+4` / `+4`**，并在超载区实际缓和排异与神经震荡症状。
- **三段状态与真实后果**：
  - **安全区**：平稳运行，无额外负担。
  - **超载红线区**：允许装，但顶栏点明具体原因（如双中枢并行、重器堆叠），并作为客观事实进入叙事与检定（连续开加速、重伤、黑客攻脑或断药时真实触发耳鸣、鼻血、手抖、视觉重影与失控前兆）。
  - **生理硬顶**：创角和义体医生手术台**直接拦截**，明确提示“神经承载已满（差 X 点），需先卸下旧件，或改用装植减缩 / FBC 躯体底盘”。
- **创角防滥选**：创角与局内共用同一套原生血肉上限（安全 38 / 硬顶 50），开局即可捏出阿列克谢（34）级硬核佣兵，但绝不可能开局全勾选塞成义体神。

## 三、UI 与交互详细方案（创角 / 局内 `P` 面板 / 义体医生 / 自建表单四端统一）

### 1. 局内 `P` 面板 →「义体」页（左 30% 纯净联动剪影 + 右 70% 双层工作台）

- **顶栏（单行紧凑 44px）**：一条三段式「神经承载条」（青绿安全区 + 琥珀红线刻度）+ 一句人话状态（如 `24 / 50 · 平稳` 或 `44 / 50 · 超载红线（双中枢并行）`），右侧仅在位于诊所时显示诊所入口；砍掉全部旧药丸堆叠、大段固定套话与 12 格温度计。
- **左栏（约 30%）**：居中极简人体剪影，**彻底删掉四周 10 组小方格、黄字 `双臂/双目` 角标和 `+N`**；已改部位透出克制微光，悬停或点选右侧任意主位/插件时精准联动高亮对应身体位置（移到「左臂」只亮左臂、移到「右臂」只亮右臂、移到「脊柱主驱」亮脊椎、移到「网络接入仓」亮大脑）；底部只留 1 行极简底盘与已装件数摘要。
- **右栏（约 70%）**：
  - **上区 · `4×2` 核心主位网格**：躯体底盘、网络接入仓、脊柱主驱、主义眼、左臂、右臂、腿部驱动、表皮主甲——左竖条稀有度染色 + 图标 + 主位名 + 义体名 + 右上角承载数字（未装呈极淡虚线框）；点击任意核心卡时展开完整能力说明（以及行为芯片状态/受损提示），平常不铺满长文。
  - **下区 · 5 标签扩展区**：`脑机神经 2/4` · `面容感官 1/3` · `躯干防护 1/5` · `手掌足部 1/4` · `外观生活 2`。卡片只保留左稀有度色条 + 图标 + 名称 + 右上角克制数字（外观件留空不显示）+ 一句话效果；彻底清除 `零负荷 / 轻负荷 / 可自由叠加 / 物理互斥` 刷屏标签与大黄框解释条。

### 2. 创角 →「义体」页

- **左栏（约 35%）**：同款神经承载条 + 居中互动人体剪影 + 已装核心/扩展速览（左右臂带一键「双臂同款」与单侧卸下）。
- **右栏（约 65%）**：两排直观分区切换（核心主位 7 项 / 扩展与生活 5 项 + `+ 自建义体`），货架内将大猩猩/螳螂刀/单分子线/射弹发射系统的 `常规 / 热能 / 电磁 / 化学` 收拢到同一张主卡内用 4 胶囊切换；装配按钮实时反映状态（`装左臂 / 装右臂 / 双臂同款`、进红线琥珀色提示、满载/满格清晰说明差多少点）。

### 3. 义体医生诊所

- **左栏（已装身体视图）**：复用同款承载条 + 8 核心主位 + 扩展件清单，每项自带 `拆下（回收）` / `维修` 操作；
- **右栏（医生货架）**：复用创角分区切换与元素变体折叠卡片，显示价格/旧件折价净付/库存；超硬顶时直接拦截并说明需腾出的承载或升级底盘。

### 4. 自建义体表单（创角内联 + 创意工坊统一）

- 一屏 4 行完成：① 名称 + 归属定位（核心主位 / 扩展与生活分组下拉）→ ② 稀有度 + 神经承载（4 档预设 + 微调，外观类自动锁 0）→ ③ 效果与限制说明 → ④ 仅显示当前定位相关的 1–2 个精简开关，零后台黑话。
