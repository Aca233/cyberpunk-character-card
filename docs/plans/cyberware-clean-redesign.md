# 义体系统分类理顺与界面去噪重构计划

> 状态：已完成

## 背景与痛点

用户反馈「义体好乱，而且也不是很合理」，根因有四：
1. **分类反直觉**：音频套件、鼻腔滤器、颌骨暗格硬塞在「面部与感官（原眼睛位）」；午夜绅士/佳人、合成费洛蒙硬塞在「循环系统」；时尚皮肤/光纹纹身混在防弹表皮；全身义体化（FBC）混在「骨骼」。
2. **规则与命名分裂**：前后端部位名不统一（`额叶皮质/额皮质`、`皮肤/表皮系统`、`手部/手掌`、`手臂/胳臂`），界面四处贴「物理互斥」「零负荷/轻负荷」「双臂/双目/混搭」「可自由叠加」补丁标签，像硬件说明书。
3. **人体图角标与框套框**：图上堆着角标和 `+` 格，卡片里也塞满标签，日常轻装反倒比核心战斗改造还抢眼。
4. **三处界面各长各的**：创角、局内 `P` 义体页、诊所使用不同的划分方式和提示语言。

## 核心设计

1. **兼容底层 10 部位 ID，重理统一直觉分区（`CyberwareSectionId` = 10 身体部位 + `lifestyle` 日常与感官 + `fbc` 全身躯壳）**
   - 保持 `CyberwareDef.slot` 与存档/NPC/预设数据零破坏兼容。
   - 统一唯一中文部位名称（消除前后端分裂）：`操作系统`、`额叶皮质`、`义眼与面甲`、`神经系统`、`循环系统`、`表皮防护`、`骨骼`、`手臂`、`手掌`、`腿部`，外加独立分区 **`日常与感官`** 与 **`全身躯壳`**。
   - 新增 `cyberwareSectionOf(def)` 与 `CYBERWARE_SECTION_LABELS` 供核心规则与三端 UI 共用：
     - 将耳鼻声纹/变色虹膜/颌骨暗格/时尚变色皮/光纹纹身/恒温皮/触觉/感官同步/内啡肽泵/亲密改造/费洛蒙归入 **`日常与感官`**；
     - 将 `fullBorg`（双子星 / 龙式 FBC）归入 **`全身躯壳`**；
     - 其余各部位只保留真正属于该部位的解剖/战斗改造。
2. **极简常识化规则与「只在必要时提醒」的负荷展示**
   - 删掉页面上「物理互斥」「可自由叠加」「零负荷件 N」「轻负荷/中负荷」等所有啰嗦标签。
   - 日常与轻度义体卡片**不打负荷标签**；仅真正高压重器（`humanityCost >= 10` 或 `iconic`）克制标 **`高负荷`**。
   - 顶部负荷摘要：轻度/常规时一句干净总览；仅在 `dualCore` / `fullBorg` / `heavy` / `extreme` 时一句直白点明原因（如双中枢并行、全身义体化、重型改造过载）。
   - 手臂/义眼/腿部成对说明收口为单行轻量辅助词（仅在物品规格本身带 `成对双臂` / `单臂挂载` / `双眼成对`），**彻底移除人体图上的黄色角标与 `+` 号挂载格**。
3. **三处界面统一简洁化**
   - **`CyberDoll`**：左侧居中人体图保留 10 个核心解剖部位（无角标、无 `+` 号、极简灰底空格），底部收一条紧凑「日常与感官」&「全身躯壳」快捷入口胶囊，点任意区域即可联动右侧。
   - **创角 `CharacterCreator` / `CreatorSteps` / `CustomCyberwareForm`**：统一切换 12 分区货架、去掉多余的负荷分类快筛，卡片只留稀有度、必要 `高负荷` 提示与明确的替换提示。
   - **局内 `CyberwarePage`**：顶部极简读数 + 右栏纯净当前分区详情（无冗余边框与标签墙）。
   - **义体医生诊所 `Ripperdoc`**：导航栏对齐 `10 身体部位 + 日常与感官 + 全身躯壳`，卡片和检视台全面去噪。
