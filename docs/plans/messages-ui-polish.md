# 消息页面视觉美化与体验优化计划

> 状态：已完成（2026-11-22）
> 目标：全面升级消息页面（`Phone.tsx`、`NewsPanel.tsx` 与左下角 `Unread` 抽屉壳层）的赛博朋克 2077 全息通讯终端视觉质感与交互效率，修复新闻栏溢出无法滚动的问题，并保持与全站原作 UI 令牌、暖暗紫黑表面色阶和 `FactionsPanel` / `ShardsPanel` 共用样式的完全解耦与协调。

## 1. 现状诊断与优化目标

1. **抽屉尺寸偏局促、新闻栏存在滚动缺陷**：
   - `.unread[data-wide]` 当前宽 `680px`、高 `min(460px, 56dvh)`，左右两栏（联系人名录 + 对话窗）在信息较丰富时略显拥挤。
   - `.unread[data-wide] .growBody` 设置了 `overflow: hidden`，而 `NewsBody` 的 `.feedSection` 缺少 `flex: 1; min-height: 0; overflow-y: auto;`，导致新闻与街头风声条目较多时被直接裁切、无法滚动。
2. **联系人查找与状态辨识度不足**：
   - 缺少联系人搜索框与「未读」快捷筛选，中后期认识 10+ 人物时查找特定中间人、义体医生或熟人较慢。
   - 联系人行缺少最后联系时间、未发草稿标识（`[草稿]`）、更清晰的在场/离线/未读视觉层级，也未突出头像上的在线状态点。
3. **对话顶栏与全息来电质感偏平**：
   - `ThreadHead` 偏扁平表单风，头像可点击/悬停展开完整档案的提示不够直观；好感度只以纯灰字呈现，缺少双向色阶或清晰语气；多职能角色只显示 1 个徽标。
   - 响铃来电横幅与未接来电列表缺少波形动效、头像与「点击切到该联系人会话」的快捷联动。
4. **聊天气泡与输入交互体验可大幅增强**：
   - 聊天区缺少全息终端底纹纵深；气泡为普通矩形边框，层次平淡；委托卡片（`phoneJobTag`）仅静态提示，无法一键填入答应回复。
   - 长对话向上翻看历史时缺少「回到底部」悬浮按钮；空会话缺少结合人物身份的快捷破冰短语芯片。
   - 输入栏缺少字数提示、快捷键提示与「转入主线行动框」常驻快捷入口，锁定状态提示也缺少图标与语气区分。
5. **新闻栏缺乏频道筛选与信息层次**：
   - N54 / 电台播报与街坊风声混排到底，缺少顶部频道切换（全部 / 街坊风声 / N54 与电台）与条目较多时的轻量搜索。

## 2. 核心设计方案

### 2.1 独立样式模块与抽屉壳层升级
- 新建 `apps/web/src/features/story/phone.module.css`，独立承载私信终端与新闻流样式，避免牵连 `story.module.css` 中被 `FactionsPanel`、`ShardsPanel` 复用的旧类。
- 适度放宽 `.unread[data-wide]` 至 `min(760px, ...)`，高度上限放宽至 `min(560px, 66dvh)`（继续受 `useRoomLeft` 动态约束，不遮挡左上角生物监测与全息来电）。
- 优化 `Corners.tsx` 的 `Unread` 折叠卡与底栏：未读态增加脉动指示点与更清晰的消息预览；展开底栏的 `ESC` 键改为可点击收起按钮，并用红→青渐变底线衔接内容区。

### 2.2 联系人目录与高效筛选
- 扩展 `ContactFilter` 增加 `"unread"` 维度（仅在有未读时自动出现，默认仍为「全部」），筛选栏采用赛博切角芯片样式并带数字角标。
- 当联系人数量超过 4 人时显示紧凑搜索框（支持按姓名、外号、职能、地名、标签与最新消息筛选，带清空按钮与命中计数）。
- 升级 `ContactRow`：左侧全息光带、头像右下角在场脉冲菱点、未读暖黄边框强调、最新时间显示、未发草稿 `[草稿]` 标签、最多 1 枚核心职能徽标与更锐利的选中态。

### 2.3 终端顶栏、全息来电与人物档案浮层
- `ThreadHead` 升级为终端通讯头：叠加轻扫描线头像、悬停/点击「档案」直观标识（并在名字区提供清晰入口）、多职能徽标（最多 2 枚）、色阶化好感度胶囊（含正负配色）、以及带原作图标的快捷操作按钮（`定位`、`进诊所`、`进主线` / `回复未读`）。
- 关键待办横幅（来活、欠款、人情、仇怨、心事）配备对应图标与红/黄警示色带。
- `IncomingCallBanner` 增加来电者头像、脉冲青色声波条与红/青接听挂断按钮；`MissedCalls` 支持一键跳转到该联系人的会话并标已读。

### 2.4 全息聊天气泡、委托快捷回填与输入终端
- 聊天舞台采用 `--cp-surface-deep` 凹陷底色 + 低透明度 `fx.grid` 网格底纹，呈现夜之城全息终端质感。
- 区分对方/玩家不对称切角气泡：对方为青色左轨 + 右下切角（未读态为金色警示光带），玩家为暖金右轨 + 左下切角；新增消息柔和入场动效。
- 升级委托信息卡（`phoneJobTag`）：展示委托图标、状态徽标、高亮欧元报酬与期限；当处于 `offered` 且可直聊时，提供「填入答应」一键填词按钮（填入后聚焦输入框，仍由玩家确认发送）。
- 历史滚动检测：向上翻看超过一屏时底部浮出「回到底部」快捷胶囊按钮。
- 空会话引导：对已照面且在线的联系人，根据其身份（中间人 / 义体医生 / 商店 / 熟人）提供 2–3 个一键填入的破冰短语芯片。
- 升级底部输入栏：自动增高文本框、`Enter 发送 · Shift+Enter 换行 · 1–3 分钟` 提示、实时字数计数器（近上限变黄/红）、突出样式的发送按钮，以及带图标与分语气提示的频道锁定条。

### 2.5 新闻与街头风声栏升级（`NewsPanel.tsx`）
- 修复滚动容器结构，让新闻列表在固定高度抽屉内顺畅独立滚动。
- 新增 `N54 WIRE // 夜之城频道` 紧凑顶栏：频道筛选芯片（全部 / 街坊风声 / N54 与电台 + 计数），条目 ≥ 6 时附带轻量搜索框。
- 精细区分「街坊风声」「附近街区传闻」「N54 / 电台快讯」卡片的左侧色轨、频道徽标、未读警示态与排版层次。
