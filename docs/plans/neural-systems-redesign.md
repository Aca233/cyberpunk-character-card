# 夜之城「超梦 · 芯片 · 性偶/玩偶」系统重做策划案

> **状态**：已确认定稿（2026-11-20），取代原 `braindance-experience-design.md`、`chip-everyday-use-design.md`、`doll-and-adult-services-design.md`。
> **适用架构**：纯定性沙盘引擎（无骰点、无属性加值、无血条/人性数值扣点），一切以**具体物理条件 × 社会因果裁决（`blocked` / `costly` / `possible`）+ 具体伤势与神经症状**运转。

---

## 一、总设计纲领

在《赛博朋克 2077》中，超梦（Braindance）、芯片（Shards/Chips）、性偶与玩偶（Joytoys / Dolls）共同构成夜之城的**神经接口生态**。本次重做遵循三条铁律：

1. **回归夜之城核心锚点**：以丽姿酒吧（莫克斯帮 / 朱迪）、云顶（虎爪帮 / 玩偶算法与行为芯片）、扭扭街（街头性偶 / 地下黑超梦）及佣兵黑市为主骨架；清除与夜之城脱节的家政/物业/文创芯片和 5 家原创同质小铺，仅保留歌舞伎「阿岚的芯片小铺」改造成正版+灰市音像芯片摊。
2. **纯事实条件，零数值膨胀**：
   - 不加任何属性点、检定骰子、加值或人性扣分。
   - 芯片能力、超梦轨道扫描、黑冰破译、行为芯片托管均以**真实硬件条件、防线等级、记忆边界、具体伤势与具体神经症状**结算。
3. **去官僚化指令与提示词**：
   - 拆除 `bd-session` / `adult-service` 的强制五元组报价表单（`ServiceTermsSchema`）与逐字引文校验（`tradeEvidence` / `evidence` / `consent`）。
   - 收束三套系统的指令与提示词体积，把模型算力从“核对法务清单”解放回夜之城沉浸体验与因果推演。

## 二、模块一：超梦系统（`braindance`）

### 2.1 四级片源生态（`tier`）

| 分级 (`tier`) | 定位与典型内容 | 主要渠道 | 沙盘后果与特征 |
| --- | --- | --- | --- |
| `commercial` 商业娱乐 | 演出、极速飙车、风光解压、流行体验片 | 阿岚小铺、街头终端、丽姿普通区 | 价格亲民，日常解压，无神经副作用 |
| `sensory` 感官调谐 | 莫克斯精修的高沉浸感官/情绪/成人片 | 丽姿酒吧（包厢点播或自带花环）、高端会所 | 强感官共鸣与风月氛围，需合规场域或自带花环 |
| `raw` 调查原片 | 未剪辑第一人称原始卷轴（案发现场、秘密交易、安保巡逻、偷录原片） | 委托、搜尸、保险箱、NPC 托付、玩家自录 | **核心侦查载体**：支持编辑模式切换三层感官轨道扫描硬线索 |
| `xbd` 地下黑超梦 | 未经滤波的非法极端感官片（清道夫地下厂牌、临终/极痛/极端刺激禁片） | 扭扭街黑摊、清道夫据点、歌舞伎/狗镇暗渠 | 高额黑市价值或关键地下线索；**强神经冲击**——直看无滤波可能当场引发具体 `humanity` 神经症状（感官解离、耳鸣幻痛、认知重叠）或身体不适 |

### 2.2 硬件条件与双模式

- **观看（`immerse` 沉浸模式）**：持有便携超梦花环（`bd-portable-player`）**或**身处带超梦设备的场域（如丽姿酒吧包厢、阿岚小铺试看机）即可播放。
- **分析（`edit` 编辑模式）**：持有编辑级超梦头环（`bd-editor-wreath`）**或**身处专业超梦调谐台/有调谐师（如朱迪）协助时，可对含线索的 `raw` / `xbd` 卷轴切换三层轨道扫描：
  - `visual`（视觉层）：人脸、门禁按键、义体编号、反光/时间水印、招牌。
  - `audio`（音频层）：加密通话、背景警笛/地铁报站、心跳频率、低语。
  - `thermal`（热感层）：暗格散热、刚藏匿的武器/人体、冰浴缸、过热义体。
- **线索揭示**：取消脆弱的子串 `cues` 匹配。只要满足分析条件且本轮针对对应轨道（或具体线索点）扫描，即可直接揭示并写入 `discoveries`。
- **主动录制（`record`）**：安装完好 `braindance-recorder`（脑机录制义体）的角色可在现场录制原始卷轴，生成实体超梦芯片用于交付取证、黑市倒卖或勒索。

### 2.3 指令模型

保留 `define`（动态登记新片），主流程收敛为 5 个清晰动作：
- `play`：开始或切入播放（`work`、`mode: immerse | edit`、`device`、`venue`）。
- `progress`：推进当前超梦段落并归档正文/媒体（取消 `tradeEvidence` 强制引用）。
- `scan`：在编辑模式下扫描指定轨道（`layer: visual | audio | thermal`、`detail`），揭示对应线索写入 `discoveries`。
- `record`：启用 `braindance-recorder` 将当前经历录成新 `raw` 卷轴并生成载体。
- `stop`：暂停、摘镜或完成本次超梦（`outcome: paused | exited | finished`）。

## 三、模块二：芯片系统（`shards`）

### 3.1 五大真实类别（`category`）

| 类别 (`category`) | 定位与典型内容 | 沙盘机制 |
| --- | --- | --- |
| `intel` 情报与数据 | 加密邮件、公司机密、帮派账本、门禁密码、夜之城读物/录音 | 读取直接解锁线索、密码、坐标或谈判把柄 |
| `daemon` 加密与陷阱 | 加密欧元芯片、子网后门/门禁密钥、带病毒或黑冰的陷阱芯片 | 破译可提取欧元或拿到真实子网切入条件；**带毒/黑冰芯片若未经读写器沙盒查毒直接直插，由 `judge` 裁决反噬**（神经症状、具体伤势或义体烧毁） |
| `skill` 技能协议 | 即时语言翻译芯片、武器弹道辅助、创伤急救协议、格斗动作库、安保频段词典 | **插入个人神经芯片槽后提供真实事实能力**（与义体同类，由 `judge` 作为客观条件采信），拔出即失效，不加数值 |
| `braindance` 超梦载体 | 承载某部超梦卷轴的物理芯片 | 与超梦系统打通，可直接播放/分析或经读写器复制 |
| `behavior` 行为协议 | 云顶玩偶托管协议、改装格斗/潜行/情绪屏蔽/伪装协议 | 配合已安装的 `doll-behavior-chip` 启用 |

### 3.2 个人神经插槽与隔离读写器

- **2 个个人神经芯片槽（`slots`, 上限 2）**：
  - 普通未加密、无毒的芯片直接插颈后槽即可读取，不再要求先买读写器才能读字。
  - `skill` / `behavior` 类芯片装入槽位后生效，拔出即停；插槽数量即硬物理上限。
- **隔离读写器（`chip-reader-writer`）的新定位**：
  - **沙盒查毒（`inspect`）**：安全检查未知来源芯片是否带加密锁、黑冰或恶意病毒，避免盲插吃反噬。
  - **离线破译与刻录（`decrypt` / `copy`）**：配合完好网络接入仓离线破译加密芯片（由硬件与加密等级因果裁决，不再卡死同地点入侵网络记录），或将芯片内容烧录到 `blank-shard`。

### 3.3 指令模型

- `chip`：`define` / `read` / `inspect`（读写器查毒）/ `decrypt`（破译解密、提取欧元或清毒）/ `equip`（插入神经槽）/ `unequip`（拔出神经槽）/ `copy`（刻录副本）。
- 保留轻量 `shard` 快捷归档命令供自由生成的现场读物落档。

## 四、模块三：性偶、玩偶与行为芯片（`commerce` + `cyberware.behavior` + `npc`）

### 4.1 夜之城三层生态

1. **扭扭街街头性偶（`joytoy`，威斯特布鲁克）**
   - 本人清醒接客，无行为芯片；明码标价、快捷成交。
   - 兼具街头情报口（醉客漏嘴、虎爪帮动向、黑超梦流向）与街头暗巷突发冲突。
2. **丽姿酒吧（`lizzies-bar`，沃森，莫克斯帮）**
   - 合规成人与感官超梦会所 + 地下室朱迪超梦调谐区；莫克斯武装维序，红线分明。
3. **云顶（`clouds`，威斯特布鲁克 H8，虎爪帮）**
   - 标志流程：前台存枪 → 个人链路接入算法匹配（解析潜意识渴望）→ 玩偶切入行为芯片托管（`doll`）→ 结束切回清醒（`off`），**本人失去托管时段记忆**；安全词可随时中止托管。
   - 核心张力：算法心理剖析、醒/睡记忆断层、芯片日志黑料、玩偶反抗与虎爪帮控制。

### 4.2 行为芯片统一四态模型（玩家与 NPC 共用）

允许玩家在义体医生处安装 `doll-behavior-chip`，与 NPC 共用同一四态模型：

| 模式 (`mode`) | 含义 | 沙盘因果与边界 |
| --- | --- | --- |
| `off` 清醒 | 本人完全主导 | 切回 `off` 时若前态为 `doll` 或深层托管，自动保留**记忆断层**（本人默认不知接管期间经过，除非查阅设备日志、他人转述或故障闪回） |
| `doll` 玩偶托管 | 由场所算法或预设温顺/陪伴人格接管 | 切入时本人意识退居后台；安全词立即切回 `off` |
| `protocol` 改装协议 | 刷入格斗、潜行、社交伪装或情绪屏蔽协议 | 提供真实动作/表现条件（如云顶改写玩偶战斗芯片），长时间或高强度运行易引发自我抽离类 `humanity` 症状，并存在被黑客干扰的风险 |
| `glitch` 故障/被骇 | 受黑客攻击、重创或黑超梦冲击 | 造成僵直、托管失控、记忆碎片泄漏或强行吐出加密日志 |

### 4.3 交易与叙事边界

- 移除 `bd-session` / `adult-service` 在 `inventory/trade.ts` 与 `commerce` 中的强制 `ServiceTermsSchema` 五元组卡死；保留轻量 `commerce.service` 记录当前在场服务会话（场所、对象、服务类型、进行状态）。
- 移除 `cyberware.behavior` 与 `npcBehavior` 的逐字 `evidence` / `consent` 引文校验，改为清晰的状态切换、日志写入、日志查阅与故障触发。
- 叙事尺度：限定成年角色；亲密场景走电影化氛围与克制拉灯描写，聚焦霓虹光影、心理博弈、算法独白与余韵，既不写露骨色情也不退化成计时收据。

## 五、内容与前端改造清单

### 5.1 内容库（`packages/content`）
- 删除 `chip-retail.ts`（5 家原创生活铺）与 `chip-library.ts`（家政/物业/种菜芯片）。
- 保留并改造 `sleeve-corner`（阿岚的芯片小铺）为歌舞伎正版+灰市音像芯片摊。
- 在 `locations.ts` / `map.ts` 新增 `clouds`（云顶，超级摩天楼 H8）与 `jig-jig-street`（扭扭街）。
- 重写 `braindance.ts`（8 部覆盖 `commercial` / `sensory` / `raw` / `xbd` 的夜之城卷轴）与 `chips.ts`（覆盖 `intel` / `daemon` / `skill` / `braindance` / `behavior` 五类芯片及编辑级超梦头环 `bd-editor-wreath`）。
- 补全云顶玩偶/前台、扭扭街性偶与黑超梦贩子，并与朱迪、艾芙琳及 `arcs.ts` 钩子对齐。

### 5.2 前端 UI（`apps/web`）
- `ShardsPanel` 升级为「神经芯片与超梦」工作台：
  - **芯片与插槽**：顶部展示个人神经槽（`已用 / 2 槽` + 已装能力），下方按 5 类筛选，显示「加密」「未查毒」「已插槽」「含欧元」等状态标签；彻底隐藏原始 `contentId / partId`。
  - **超梦台**：展示分级徽章（商业 / 感官 / 原片 / XBD）、活跃超梦的三层轨道（视觉 / 音频 / 热感）扫描状态与已揭示线索卡，支持回看。
- `InventoryPage`：把芯片、超梦载体、超梦头环与读写器从“杂物”中独立分类显示。
- `ContactsPage`：对植入行为芯片的 NPC 显示状态胶囊（清醒 / 玩偶托管 / 改装协议 / 芯片异常）。
