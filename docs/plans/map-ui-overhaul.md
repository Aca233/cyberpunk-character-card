# 夜之城地图界面美化与交互优化计划

## 现状问题诊断

1. **顶栏拥挤且存在重复按钮**：`当前位置：xxx` 徽章与工具栏里的「当前位置」按钮功能重复；搜索框、缩放条、切换键全部平铺，容易折行且缺乏 2077 战术抬头层次。
2. **右下角图例默认全展开，严重遮挡视口**：20 个筛选开关默认 3 列全展开占掉近 1/4 地图视野；核心标记与 12 类商铺混排，缺少一键「精简战术」视图预设。
3. **搜索与快速跳转不够顺手**：搜索框缺少清除按钮和方向键（`↑ / ↓`）导航，空输入聚焦时无城区/重点目标（委托、住处、停放载具）一键飞跃入口。
4. **左下角路线详情卡与右上角城区卡层次偏平**：路线卡里住处、载具、委托、警情、人物共用单调列表，出行选项的耗时/费用/风险缺乏色彩语义区分；城区卡在亮色底图上对比度偏弱。
5. **地图画布氛围与导航动效偏素**：缺少克制的 HUD 暗角与取景刻度，地点名牌为简陋黑条，选中路线连线为静态虚线。

## 实施方案

- [x] **阶段一：重构 `MapPanel.tsx` 交互与信息结构**
  - 精简顶栏：保留 `NC // TACTICAL MAP · 夜之城` 双层抬头与单一高亮「当前位置」定位按钮（移除工具栏重复的「当前位置」按钮）。
  - 升级搜索框：支持清空按钮、键盘 `↑ / ↓ / Enter / Esc` 选择；空输入聚焦时展示「关键目标」（进行中委托 / 住处 / 停放载具）与「城区速览」（7 大城区一键居中）。
  - 图例面板默认改为紧凑收起胶囊（支持 `localStorage` 记忆展开偏好），内部按「核心态势」与「商铺与设施」分组，新增「全部显示 / 精简态势 / 全部隐藏」快捷预设。
  - 重构左下角路线卡：按住处（金）、载具（绿）、委托（红）、警情（蓝）、风声（黄）、人物（青）分层着色展示；出行方式拆分耗时、费用徽章（免费绿/付费黄）、分色风险胶囊与悬停「出发 →」提示；路径连线中点新增最快耗时胶囊。
- [x] **阶段二：升级 `story.module.css` 地图视觉体系**
  - 增加视口暗角与四角 HUD 细线取景器，升级动态流动战术路线虚线（遵循 `prefers-reduced-motion`）。
  - 升级地点名牌（暗底玻璃 + 左侧战术细边 + 悬停/选中高亮）、右上角城区卡暗底半透明底板与顶边红线、路线卡与图例面板的暗色玻璃层次。
  - 将操作提示改为底部居中悬浮状态栏，避免与左右角卡片碰撞（小屏自动收起）。
- [x] **阶段三：静态检查与验收**
  - CSS Module 137 个类名交叉校验 0 缺失。
