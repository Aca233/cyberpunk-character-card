# 地点栏电子战状态清理与 HUD 归位方案

> 状态：已完成（2026-11-23）
> 目标：清理右上角地点框（`Zone`）下方混排的电子战杂项列表，按信息归属将热负荷、反追踪、破冰与生效破解归位至最符合直觉的既有位置，消除重复展示与点击误触地图的问题。

## 1. 现状问题

目前 `apps/web/src/features/story/Corners.tsx` 的 `Zone` 组件在地点框下方把 5 类不同维度的状态全部堆进了 `.zoneThreats`（且整块包在 `onClick={onMap}` 打开地图的热区里）：
1. **地区势力威胁**（如 `★ 清道夫 势力`）—— 属于地点维度。
2. **已攻破局域内网**（`view.hacking.breaches`）—— 属于当前地点环境控制权。
3. **接入仓热负荷**（`热负荷：过载临界 5/6`）—— 属于主角自身硬件状态，与地点无关。
4. **反追踪警报**（`反追踪：米格尔 2077-04-12 21:18`）—— 属于敌方电子反制警报，且完整年月日与上方时钟重复。
5. **破冰立足点 + 最近破解流水**（`已破冰：米格尔 立足点`、`破冰入侵 → 米格尔`、`过热 → 米格尔 伤害`）—— 既与「已破冰」语义重复，又会在场景内越积越长，把右上角拉成一长串日志。

同时，左上角「生物监测 → 接入仓」页签（`CyberdeckPage.tsx`）与底部输入框「接入仓快捷栏」（`DeckQuickbar.tsx`）已经完整承载了热负荷、场景电子战态势与目标破冰标记，导致信息多处重复、右上角主次失衡。

## 2. 推荐改法（按归属分流）

### 2.1 右上角 `Zone` 地点框：只保留「地点相关」信息

- 保留：地区势力威胁（`shownThreats`，最多 3 行）与当前地点已攻破局域内网（`view.hacking.breaches`，如无则不显示）。
- **整段移除**：`Corners.tsx` 第 1670–1724 行的 `热负荷 / 反追踪 / 已破冰 / activeEffects` 列表块。
- 效果：右上角重新干净利落，只负责地点、时间天气、通缉星级与本地威胁/内网，不再出现「点热负荷结果弹出地图」的割裂感。

### 2.2 左上角 `BioMonitor` 硬件状态行：承接「自身热负荷与反追踪告警」

- 在 `Corners.tsx` 的 `BioMonitor` 底部 `bioLine`（现有 `DECK · ...` 行）：
  - 热负荷升高（`heat > 0`）时，紧跟 `DECK` 标签或右侧状态位展示紧凑刻度（如 `热 5/6`，`hot` 暖橙、`critical` 危红）。
  - 触发 `traceAlert` 时，在右侧告警位高优先级显示红色 `反追踪` 提示（悬停查看目标与时分，点击可展开接入仓页签）。
- 平时常温无警报时保持原样，不增加任何视觉负担。

### 2.3 底部 `InputBar` 接入仓按钮 + `DeckQuickbar`：承接「出手前防误发提示」

- **`InputBar` 接入仓按钮**（`InputBar.tsx`）：
  - 在按钮内接入仓名称旁挂轻量化状态胶囊：热负荷达到 `hot` / `critical` 时显示 `5/6`（暖橙/红），有反追踪时显示红色警示点或 `反追踪` 短标，玩家准备出招时一眼就能看见是否快过载。
- **`DeckQuickbar` 快捷栏**（`DeckQuickbar.tsx`）：
  - 已有目标 `已破冰` 标签与顶栏 `热 X/6`。
  - 补充：当存在 `traceAlert` 时，在 `meta` 区或顶栏显示一条简短的红色 `反追踪 · 米格尔` 警报，并在目标 `title` 悬停提示里附带该目标当前生效的破解效果（如 `生效中：过热`）。

### 2.4 `CyberdeckPage` 场景电子战态势去重与精简

- `CyberdeckPage.tsx` 中的 `FIELD // 场景电子战态势` 继续作为完整明细查看页：
  - `反向追踪警报` 的时间仅展示时分（或相对简洁格式），去掉冗余年份日期前缀。
  - `生效中的破解` 展示时过滤掉与 `已破个人黑冰` 重复的「破冰入侵」记录，避免同目标同时出现「已破冰：米格尔」和「破冰入侵→米格尔」。

## 3. 备选极简方案（如果只想先做减法）

如果希望变动范围最小，也可以只执行 **2.1 + 2.3**：
- 直接删掉地点框下的电子战状态列表；
- 仅在底部 `InputBar` 接入仓按钮与 `DeckQuickbar` 补齐热负荷/反追踪提示（完整明细仍留在「人物 → 接入仓」页签）。
