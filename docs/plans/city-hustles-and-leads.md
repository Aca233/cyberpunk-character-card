# 夜之城活源看板与地图直达（拳赛 / 赛车 / NCPD 悬赏 / 中间人渠道）

> 状态：已完成（2026-11-26）

## 目标

解决“底层已写好 8 类委托、8 个 NCPD 警情模板、6 场拳赛/赛车和中间人派单体系，但玩家打开追踪面板和地图时缺少直观主动入口”的玩法空洞（**绝不凭空刷事件**：NCPD 警情仅随时间自然浮现，中间人仅显示已相识或通讯录中可联系者）：

1. **补齐核心视图坐标与据点字段**：
   - `sidegigsView` 补充 `locationName`、`district`、`x`、`y`；
   - `jobsView.fixers` 补充 `location`、`locationName`、`district`、`met`、`alive`。
2. **追踪面板（J）新增「夜之城活源」分区与筛选标签**：
   - 聚合展示自然出现的 **NCPD 街头悬赏**、城中既有场馆的 **地下拳赛与街头赛车**、以及 **已相识/通讯录中的中间人渠道**；
   - 支持一键「地图定位」、已在现场一键「前往处理 / 报名开赛」（写入行动草稿）、以及一键「发消息找活」（直达手机对应中间人聊天）或「打听活计」。
3. **夜之城地图（M）新增「拳赛与赛车」图钉层与搜索/快捷聚焦**：
   - 在地图核心态势图例中默认开启 `sidegigs`（拳赛与赛车）图钉，点击直达场馆路线卡；
   - 路线卡清晰标明赛事类型、对手、段位与押金/奖金；地图搜索与快捷目标纳入 NCPD 悬赏与未击败赛事。
4. **与势力、地盘火拼、帮规污点、通缉热度实打实机械联动（拒绝孤立系统）**：
   - **拳赛/赛车 ↔ 势力**：绑定主办/看场势力（虎爪帮、幽冥犬、阿德卡多），本帮或自己人免押金、友好 7 折、敌对/见面就打拒绝报名、城区爆发地盘火拼自动暂停开赛；赢下中/高阶看场赛事可将中立看场势力推至友好。
   - **NCPD 警情 ↔ 势力与通缉**：涉帮警情按当前城区地盘归属动态绑定掌权帮派（或清道夫），动自家帮派场子直接触发帮规污点（`faction strike`），动别家帮派触发态度恶化，累计帮警局摆平 3 起可赢得 NCPD 友好；3 星及以上通缉时冻结外包赏金结算。
   - **中间人渠道 ↔ 势力**：卡片直出中间人所属势力、本帮标识与结仇停单状态。
