## 明确边界

1. **原 UI 固定造成的文案差异**：原人物面板把没有恢复倒计时的伤口统一显示成“即将恢复/长好”。新后台对未治疗重伤保留 `healsAt:null`，不会因此恢复。这个文字不准确已在独立浏览器验收中确认；没有通过伪造恢复时间或改面板掩盖问题，也没有修改前端源文件。其他原有数字标签仍可能保留，不能把状态条当作新的扣点规则。
2. **本次没有重做全部经济与社会模拟**：精确余额、参考价、实际持有数量、商人库存周期、部分声望/关系摘要和固定内容模板仍存在。已去掉审查中的等级锁货与任务固定奖励；尚未实现完整供需物流、自由议价记账或全城逐个个体的自主决策，不能宣称所有系统都由涌现产生。
3. **存档结构已改，不做历史兼容**：伤势、症状、现场记录、物件与破解状态采用新结构。没有迁移旧存档，也没有改写或删除本地旧数据。验收基于当前版本新建状态；旧记录重放到新引擎不在本轮兼容范围，体验新规则应新建测试存档。
4. **没有真实模型评测或费用结论**：本轮落实的是规则一致性和联动修复。普通行动仍为判断、正文、抽取三次主调用，摘要和必要的场外推演另计。上下文裁剪、整轮修复总额、最终请求预算和更少调用路径仍按策划案后续实施，不能把本轮称为“完美引擎”或已完成 token 优化。
