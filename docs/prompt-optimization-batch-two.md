# 提示词优化第二批交付记录

日期：2026-11-16。基线 `f98edd8`。用户明确要求以正文质量为主，原界面保持原样。

## 已实施

1. **长场景有持续记忆。** 每轮抽取顺带更新最多 600 字的场景提要，重要事实、承诺、计划和疑问单独增量保存。旧锚点不会因为本轮没有提及而消失；明确结清需要对应记录和本轮原文证据。登记时间随记忆提供，相对日期要求写成具体日期，减少“明天”不断向后顺延的问题。
2. **记忆参与生成正文。** 当前提要与相关锚点进入判断、正文、抽取的共同上下文。未直接展示的锚点仍可检索；已收场的未兑现约定继续存在。相关性选择控制单次请求大小，不删除持久记录。
3. **正常收场合并摘要。** 摘要在原抽取请求中生成，普通自由行动和正常收场均为判断、正文、抽取三次调用；触发场外推演另加一次。摘要缺失、格式/人物错误、明显贫乏或无来源关联时，仍单独调用摘要模型恢复。检查只能拦截明显退化，不能证明摘要语义完整或无幻觉。
4. **摘要失败不丢记忆。** 恢复摘要读取本场提要、持久锚点及必要原文。超长输出不再截掉末尾限定语。若两份摘要都失败，完整提要进入待整理记忆并保持可检索，下一场更新不会覆盖掉它。无效记忆更新保留此前内容，也不把有效正文标为状态结算失败。
5. **场外材料按成功进度推进。** 只发送上次成功游标之后尚未处理的正文，同一分钟的新行动仍会进入。保留全人物短索引；到期事项、相关委托、当前提及人物提供详卡，另补远端自主活动材料。因果必需人物没有固定 12 张截断，保留人物口吻、诉求和底线。
6. **场外失败整批恢复。** 解析完整且全部业务结算成功才提交消息、动静和成功游标。半份结果整批放弃，不发送半份消息、不推迟待办期限。失败后按游戏时间 15/30/60/120 分钟退避，避免每个小动作都重新调用。
7. **辅助连接异常不吞掉正文。** 正文及主要状态已结算后，场外推演或摘要请求连接中断仍能保存本轮内容和恢复信息；玩家主动停止仍终止回合。相关变化通过有序补丁一同保存、重放和撤回。

场外提问、闪回和未完整结算的回合不写入现在线场景记忆。没有增加两次调用主链，也没有用关键词跳过判断。

## 成本与质量取舍

- 固定全角色开局场外提示词样本，估算输入从 **11,243 → 10,092 token（约 −10.2%）**。使用项目估算函数，非真实计费，也不是整轮开销降幅。
- 三个 24 轮长场景样本中，独立记忆向各阶段增加约 **124–126 个估算 token**。这是为了保住早期承诺、未实行计划和人物关系边界；不要求所有优化都减少 token。
- 正常收场通常少一次独立摘要请求，但增加了抽取中的记忆输出；最终费用取决于模型、输出长度及质量恢复触发率，尚无整体费用结论。
- 未改连接配置、正文输出上限、预设或真实存档。锚点的原文匹配能验证引文存在，无法自动证明模型对引文的解释正确，仍需真实输出评估。
