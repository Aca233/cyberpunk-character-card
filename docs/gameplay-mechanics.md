# 《赛博朋克 2077 角色卡》玩法与机制总览

> **历史机制说明，已不适用于当前沙盘版本。** 本文仍含旧骰点、属性门槛、场次配额和固定正文风格，不应作为实现或测试的验收依据。现行规则请看 [沙盘后台清理交付](sandbox-cleanup-delivery.md)、[商店沙盘交付](merchant-sandbox-delivery.md) 和 [玩法与逻辑检查](gameplay-logic-audit-2026-11-17.md)。

> 从代码（`packages/core`、`packages/content`、`apps/web`、`apps/server`）反推出来的机制说明。
> 文中数值都取自源码里的常量；凡标「代码」的就是硬规则，标「提示词」的是写给叙事模型的约束。

---

## 0. 一句话定位

夜之城文字角色扮演。大语言模型扮演**所有人**（每个 NPC + 夜之城本身），玩家扮演自建佣兵，用自由文字行动。
**模型只管"发生什么"，代码管"账怎么记"**：属性、骰子、欧元、生命、人性、时间、物品、关系，全部由代码结算，模型只提交"事件"。

技术形态：pnpm monorepo（`apps/web` React 19 + Vite / `apps/server` Hono / `packages/core` 纯逻辑 / `packages/content` 静态数据）。
可纯前端静态托管：存档、角色卡、模型密钥都在浏览器 IndexedDB，前端直连模型 API；也可用本地 Hono 服务器模式。

## 1. 核心循环

### 玩家视角

1. 在输入框写一句行动（"我把枪顶在他下巴上，问他货在哪"），或点界面上的按钮（扫描、买东西、接委托、装义体……）。
2. 系统读到这一轮：可能不用掷骰，也可能在正文里直接给出这次行动的结果。
3. 读正文（每轮 100–350 字，以对话为主，停在 NPC 说完话的地方），看左边状态栏与下方 0–5 个建议选项。
4. 世界同时推进：时间、伤势、人情、警星、消息、传闻都在动；回合一多，前情被压成摘要。

### 引擎视角：一轮五步 + 两个后台任务

| 步骤       | 谁做                     | 做什么                                                                                                                                                                       |
| ---------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ① 判断     | 叙事模型（JSON，低温度） | 输出 `read`（复述玩家意图）、`ooc`（是否场外提问）、`check`（要不要检定、档位）、`gate`（属性门槛）、`buy`（要买什么）、`recall`（调哪些旧记忆）、`foes`（对手这轮想干什么） |
| ② 拼上下文 | 代码                     | 预算分配 → 挑规则模块 → 检索旧记忆 → 查设定库 → 裁到窗口内                                                                                                                   |
| ③ 写正文   | 叙事模型（纯文本，流式） | 边收边放；检定在这一步之前已由代码掷好，结果以"【本轮已定的事】"注入                                                                                                         |
| ④ 抽取     | 辅助模型（JSON）         | 从正文反抽"账"：`changes[]`（各种指令）、`choices[]`（建议选项）、`voices[]`（内心声音）、`messages[]`（消息）                                                               |
| ⑤ 核对     | 辅助模型（`<patch>` 块） | 逐条 `keep` / `drop`（正文里没依据）/ `fix`（写重了改小，只能往轻里改）                                                                                                      |
| ⑥ 结算     | 代码                     | schema 校验 → 业务规则过滤 → `registry.applyCommands` 按依赖拓扑逐条结算（单条失败整条不生效，连锁最多 8 层）                                                                |
| ⑦ 收尾     | 辅助模型 ×2              | 场外推演（城里在发酵的事）、场景摘要（本场压成 100–200 字）                                                                                                                  |

关键设计约束（提示词常驻守则）：
- 玩家角色是玩家的：模型不替他说话、做决定、定感受，只写别人怎么回应和身体反应。
- 你知道的不等于角色知道：秘密、暗中的事，角色没见到就不算知道。
- 世界自己在动：没人理会的威胁会逼近，人情会被追讨，街上的事会传开。
- 账归代码：模型不改数。

## 2. 检定系统（核心概率引擎）

### 2.1 属性

五项，照原作：**肉体 body / 反应 reflexes / 技术 tech / 智力 intelligence / 镇定 cool**。
建档时每项从 **3** 起、7 点自由分配、单项最高 **6**；游戏中上限 **20**（`ATTRIBUTE_MAX`）。有效属性 = 属性 + 义体加成，封顶 20。

### 2.2 骰子：爆骰的 1d10

- 掷 1d10；**掷出 10 再掷一次累加**（10+1…10+10 = 11–20），**掷出 1 再掷一次扣减**（1−1…1−10 = 0…−9）。
- 追加的那一次不再爆骰。命中 `10` = 大成功（critical），命中 `1` = 大失败（fumble）。

### 2.3 难度值 DV：档位查表，模型不写数字

模型只选**对手档位** + **上下沿**，DV 由代码查表（`OPPONENT_TIERS`）：

| 档位             | 典型               | DV 区间 |
| ---------------- | ------------------ | ------- |
| street 街头混混  | 小混混、路人       | 9–13    |
| veteran 帮派精锐 | 帮派精锐、公司保安 | 15–17   |
| elite 精英       | 荒濑精英、MaxTac   | 21–25   |
| legend 传奇      | 传奇人物           | 27–29   |

最终 DV = 基础 DV + 难度修正（上限 +4）+ 难度模式修正。
（模型若还写数字 DV，`legacyDvToEdge` 会按最近的上下沿改写并给提示。）

### 2.4 修正：一档 = 2，三条各自封顶 4

- 加成 `bonuses`：每项 **+2**，合计最多 **+4**（`BONUS_CAP`）。
- 减值 `penalties`：每项 **−2**，合计最多 **−4**（`PENALTY_CAP`）——轻伤 −2、重伤 −4、起疑 −2、戒断等。
- 难度修正 `dvMods`：每项 **±2**，合计最多 **+4**（`DV_MOD_CAP`）。
- 模型只写**来源 + 理由**（"本事：枪法""义体：螳螂刀""准备：先踩过点"），数由代码统一给。
- **对手义体**：与有卡的人对抗时写 `opponent`，对方装着利于这项属性的义体会自动 +1 档（+2），同一检定只加一次。

### 2.5 成功判定与成功率

```
检定值 modifier = 属性 + 加成(≤4) − 减值(≤4)
需要掷到      need = DV − modifier
结果          roll + modifier ≥ DV  → 成功
```

`successChance(need)` 枚举 100 种骰面，返回整数百分比（界面直接显示 0–100%）：

| need   | 2   | 3   | 5   | 8   | 10  | 13  | 15  | 18  | 20  | ≤0   |
| ------ | --- | --- | --- | --- | --- | --- | --- | --- | --- | ---- |
| 成功率 | 18% | 17% | 15% | 12% | 10% | 8%  | 6%  | 3%  | 1%  | 100% |

**这条曲线决定了整个玩法重心**：裸属性和平均骰很难过普通混混（属性 6 打 DV 9 只有 17%），想过就靠堆准备——本事、义体、物品、队员、先机、情报各换一档（+2）。

### 2.6 门槛 gate：够就成，不掷骰

属性达标即直接办成、不掷骰；不达标这条路现在走不通（让世界拒绝，或换条路）。门槛值按故事阶段给区间：**早期 4–8、中期 9–14、后期 15–20**（`GATE_LEVELS`）。

### 2.7 三种难度模式（建档时定，模型不能改）

| 模式                     | 规则                                                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 街头传说 streetLegend    | DV **−2**；致命失败总有退路，角色不会死，代价落在欧元/人性/关系上；濒死撑到期限没人救，会被人拖出来救（欠下人情） |
| 夜之城 nightCity（默认） | 标准                                                                                                              |
| 死亡之城 deathCity       | DV **+2**（计入修正上限）；死了就结束；致命的危险必须先在正文明确提示，没提示过的失败不能致死                     |

伤害档位**不受难度模式影响**（只有断肢判定会看模式：街头传说不断肢，死亡之城大失败升到致命也会断）。

### 2.8 附属小游戏：入侵协议矩阵（可选开关，默认关）

开着时，智力检定前先玩矩阵小游戏：解开第 1、2 段各 **+2** 加成，三段全解再 **−2 DV**（只对智力检定算）。

### 2.9 伤害与失败后果

`check` 里可以事先写 `damage: graze | heavy | lethal` 和 `limb: true`（断肢风险，只能与 lethal 同时写）。
规则：**检定成功不扣血；没写伤害档失败不扣血；大失败最多比事先写的档高一级；同一次检定只扣一次血；护甲义体再降一档**（多件也只降一档）。

## 3. 角色创建：8 步捏人

草稿存 localStorage，中途关页面能接着捏；原作素材驱动（人体分层图、原作模块卡）。

| 步                 | 内容                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 1 出身             | 街头小子 / 流浪者 / 公司员工 + 自写；出身决定开局住所与行装，并给后面掷"过往"加权                                        |
| 2 过往（生命路径） | 掷骰翻卡，一次一段，最多 **3 次重掷**，也可从卡片墙手挑；前 3 段必填、最多 5 段                                          |
| 3 旧识             | 给原作人物选关系（不限人数），决定开局好感、人情/仇、关系笔记                                                            |
| 4 本事             | 卡片墙：13 块本事，每块写能力 + 对哪几项属性检定有利；点一下插上、再点拔下                                               |
| 5 义体             | 用原作人体图按部位装开局义体（普通～传说都能装，只受部位格数和点数限制）                                                 |
| 6 属性             | 5 项从 3 起、7 点、单项上限 6；可"按我的本事推荐"一键分配                                                                |
| 7 这个人           | 姓名/外号/代词 + 外貌、背景故事、性格、说话方式四块正文；一键成稿一次写四块保证互相对得上，之后可逐块重写/续写/润色/锁定 |
| 8 档案确认         | 地图点图钉选开局地点（默认丽姿酒吧）；整张卡预览，不合规的检查项直接链回对应步                                           |

### 两套点，分开算

- **属性点**：起值 3、额外 7 点、建档单项上限 6。
- **背景点**：共 **12**（`BACKGROUND_POINTS`）；负面经历最多返还 **6**（`REFUND_MAX`），超出部分作废。

模块标价（`MODULE_POINTS`）：出身 0–2、过往 1–4、本事 1–4、负面经历 1–4（返还是它的点数）。
必填下限：过往 ≥3、本事 ≥3；上限：过往 ≤5、本事 ≤6、负面经历 ≤4。
内容包现成 **32 块模块**（出身 3 / 过往 10 / 本事 13 / 负面经历 6）+ 7 条联动。

### 联动（combo）

几块模块的 **id 或标签**凑齐（至少 2 块不同模块参与）即触发一条联动，带来新能力和钩子。差一块就能凑成时界面提前预告"再插一块『枪法』→ 解锁 XX"。

### 旧识关系表（花/返背景点，决定开局好感）

| 关系       | 开局好感 | 附带         | 背景点 |
| ---------- | -------- | ------------ | ------ |
| 点头之交   | +5       | —            | 0      |
| 老朋友     | +30      | 关系笔记     | 花 2   |
| 他欠你人情 | +15      | 人情 owesYou | 花 2   |
| 你欠他人情 | +10      | 人情 youOwe  | 0      |
| 前任       | +10      | 关系笔记     | 0      |
| 旧仇       | −30      | 仇 grudge    | 0      |

负面关系（你欠人情、旧仇）**不花也不返点**。

### 义体耐受

| 档          | 人性消耗系数 | 背景点 | 钩子                     |
| ----------- | ------------ | ------ | ------------------------ |
| 低耐受 low  | ×1.3         | 返还 2 | 装一件难受好几天         |
| 普通 normal | ×1.0         | 0      | —                        |
| 高耐受 high | ×0.7         | 花 3   | 有公司研究员想知道为什么 |

开局人性上限 = 100 − round(开局义体消耗 × 系数)。开局义体按稀有度算点：普通 1 / 罕见 2 / 稀有 3 / 史诗 4 / 传说 5（不朽件只能进剧情后找医生装）。

### 没变的写法：**没有开场正文**

开档后不自动写开场，等玩家写第一句。开场由内容包提供：`openings.ts` 5 个开场（部分标了 `hidden`，只给旧存档用），各有地点、只给模型看的前提、开局装备、开局期限、开局委托、初始欧元/义体、种哪些人物卡。另有按出身/经历匹配的"行装"（loadout）替代开场自带装备。

## 4. 角色成长

- **街头声望**：0–50 级，初始 1，半级累积（两个半级升 1 级）。模型只写 small/medium/large = **0.5 / 1 / 2** 级。里程碑：0 无名小卒 / 10 小有名气 / 20 道上有名 / 35 响当当 / 50 传奇。
- **每 5 级得 1 个属性点**（`LEVELS_PER_POINT`），回角色卡自己分配。
- **生命上限 = 150 + 肉体×20 + 声望×5**（肉体或声望变动即重算）。
- 声望同时决定：能接的委托星级（<10 → 2★、≥10 → 3★、≥20 → 4★、≥35 → 5★，与中间人好感取小）、商店与义体医生的稀有度门槛、NPC"别人眼里的你"。
- **习惯**：叙事模型可提议一条角色习惯（≤40 字），**玩家确认才入卡**，共 8 条，不加数值只影响描写。
- **闪回**：遇到与某段"过往"有关的人事物可插一段 **最多 3 轮**的闪回；闪回里**不掷骰、不推进时间、不记账**，只能写 `flashback` 指令；结束时留一条"已确定事实"（≤200 字，最多 24 条）回到现在。每段过往一生只能闪回一次。

## 5. 生命与伤害

| 概念        | 规则                                                                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| HP          | `hp / max`，归零即倒下                                                                                                                        |
| 伤害档      | 擦伤 graze **10%** / 重击 heavy **30%** / 致命 lethal **60%**（按生命上限取整，向上）                                                         |
| 伤势标签    | ≥60% 无伤；30–59% 轻伤（检定 **−2**）；1–29% 重伤（检定 **−4**）                                                                              |
| 护甲义体    | 伤害降一档（致命→重击→擦伤），多件也只降一档                                                                                                  |
| 归零        | 致命档 → **濒死 dying**；非致命档 → **倒下 down**                                                                                             |
| 重伤失血    | 重伤拖过 **2 天宽限**后每天 **−10%**（最多扣到 1，不会因此濒死）                                                                              |
| 断肢        | 需"事先写明断肢风险"+"降档后仍是致命"+ 难度允许；断的部位相关检定 **−2**，双手武器/追车受影响；打在义肢上改记为**义体损坏**（修好前失去能力） |
| 救治 revive | 濒死救回到 **10%**，倒下醒来到 **30%**（创伤小组是唯一能救濒死的途径）                                                                        |
| 治疗        | 治疗品按 `healPercent` 回血，但**重伤时最多回到 29%**；休整回到 60%（重伤靠休整好不了）；义体医生直接治满                                     |
| 死亡        | 由代码判定（`health.die`）；街头传说模式不会死                                                                                                |

## 6. 人性与赛博精神病

人性是一条 **0–100、上限会被义体永久吃掉** 的资源。
- **上限** = 100 − 已装义体消耗合计（经耐受系数折算，封顶 100）。
- **扣除按档**（模型只报类别和大小，不写数字）：残忍小/中/大 = **−2 / −3 / −5**；失去重要的人 = **−10**；休整小/中/大 = **+3 / +5 / +8**。
- **单次扣除封顶 −15**；**正面恢复每天最多 +8**（按 1440 分钟游戏日切分），且永远不能超过上限。
- **阶段**：≥70 稳定 / 40–69 疏离 / 20–39 不稳定 / 1–19 边缘 / 0 危机。阶段变化会推系统通知，界面按 0 / <25 / <40 三档给不同的故障特效。
- **赛博精神病**：人性 < **40** 才注入规则、才允许发作；一个场景最多发作 1 次；`severe` 发作会留下一段**记忆空白**（界面上折叠，只列最近 3 段）。
- **压制剂**：500 欧元，药效 6 小时；7 天内吃 ≥3 次开始**耐受**（药效减半），14 天内 ≥5 次**依赖**，停药 1 天进**戒断**（检定 −2）。
- **危机章节**（人性归零，`humanity.zero` 信号）：三选一 ——
  - `pulledBack` 被身边的人或诊所拉回来：人性回 **20**，拆到最多留 **2 件**义体、消耗合计 ≤30，进入 **7 天**恢复期（恢复期禁止买新义体、禁止接单）；
  - `lastStand` 带着全部义体走向最后一战；
  - `surrender` 向暴恐机动队投降。

### 斯安威斯坦（加速义体）

生死瞬间可开：一回合塞进 **2–5 个动作**（按稀有度：普通 2 / 罕见 3 / 稀有 3 / 史诗 4 / 传说 5）。代价是人性 **−count**（首次 −1，60 分钟内连续第二次 −2，依此类推）。

## 7. 装备、义体与经济

### 物品栏

3 个武器格（可切手持）+ 2 个快捷栏（治疗品 / 手雷，各记次数）+ 6 格服装（头/面/外/内/腿/脚，不提供护甲）+ 背包（不限容量）。
类别 7 种、武器类别 10 种、稀有度 5 档（普通→传说）。内容包 **128 件物品**。
- 武器类型：power 威能 / tech 技术（检定用技术）/ smart 智能（检定用智力）；近战只能装插件。
- 改装 3 位：枪口 / 瞄准镜 / 插件，每位置 1 件。
- 快捷栏次数在**休整、场景结束、战斗结束**时回满。
- **拆解与升档**：拆一件得零件（普通 2 / 罕见 4 / 稀有 8 / 史诗 14 / 传说 24）；升稀有度要零件 + 技术（罕见 5/3、稀有 10/5、史诗 20/8、传说 35/11）。
- **不朽（iconic）物品只能从剧情获得**：商店不卖、不能卖、不能拆。

### 义体

10 个部位，格数照原作：额叶皮质 / 神经 / 循环 / 皮肤 / 骨骼各 **3**，眼 / 手各 **2**，操作系统 / 手臂 / 腿各 **1**。
装满了才把该部位**最早装的那件**换下来。内容包 **116 件义体**。
- 加成：属性 **+1～+3**（多件累加）；`armor` 护甲（降一档伤害）；`accelerator` 加速（斯安威斯坦）；`programSlots` 1–12（程序位）、`ram` 1–12（RAM 格）。
- 义体医生：货架价 = 参考价 × priceFactor（0.5–2，折到百位）；**旧件折价回收 20%**；**修理 = 参考价 30%，最低 100**；`credit` 可赊账，**赊账期限 7 天**（自动挂一条期限，到期医生派人来催）。
- 医生也看街头声望门槛与好感（稀有 20 / 史诗 40 / 传说 60）。
- 打坏的义体修好前**失去能力、不算加成、不能开加速**。

### 欧元（唯一货币）

- 余额整数、不可为负；不够就**整条指令不生效**（模型只能写成讨价还价、赊账或被拒）。
- 单条 `money` 上限 **100,000**。
- 服务价目：吃 15 / 酒 10 / 住一晚 40 / 打车 30 / 情报 200 / 看伤 300 / 罚款 500 / 打点 100。
- 讲价档：none ×1 / small ×0.8 / large ×0.5，折后舍到十位、最低 10。
- 卖出：基础回收 **参考价两成**，讲价后最多三成。
- 商店补货周期 **3 个游戏日**；每批进货量按稀有度（治疗品/手雷 5、普通 3、罕见 2、稀有以上 1）。
- 势力态度乘价：敌对 ×1.3 / 中立 ×1（无影响）/ 友好 ×0.9 / 自己人 ×0.8 / 见面就打 → 不卖。
- 掉落零钱按档位：街头 50/150/400、精锐 200/500/1200、精英 600/1500/4000、传奇 2000/5000/12000。
- **大额确认**：一次花掉 **>1000 欧元且超过存款一半**时，界面先停下来问（`isBigSpend`），确认后带 `spendOk` 再发。

## 8. 战斗：没有回合，只有案底

打斗完全交给叙事（位置、埋伏、情报、人数、手里的家伙），代码只登记后果：
- `combat start`：登记在场敌人 1–5 条，路数 gunner / brute / netrunner / boss，档位 street / veteran / elite / legend。
- `combat foe`：某人 up / down / dead / fled；**只有倒下或死亡才能搜身**，跑了就带走东西。
- `combat wound`：玩家挨打，写清 by（谁）/ weapon（用什么）/ part（打哪）/ tier（档位）——战斗中**只能走这条路扣血**，模型另写的 `damage` 一律丢。
- `combat loot`：从倒下的人身上捡（战斗里模型自己编的 `item gain` 不认）。
- `combat end`：写看见的人数、有无摄像头、一句真相 → 生成**流言**与**录像**。

后果链（这才是战斗的长期代价）：

| 后果     | 规则                                                                                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 伤口愈合 | 擦伤 1 天 / 重击 4 天 / 致命 10 天；付费治疗后按一半时长算                                                                                                                         |
| 留疤     | **未处理的重击、致命**愈合后永久留疤（擦伤不留）                                                                                                                                   |
| 治伤     | 300 欧元（服务 medical）                                                                                                                                                           |
| 流言     | 每 1440 分钟传到新地区并**随机走样一处**（人数翻倍、动机、脸、手法），传 4 跳后淡去；收买 500 欧元                                                                                 |
| 录像     | 2 天到期：监控 → 直接进 NCPD / 贩子 / 敲诈者之一；路人拍的先在目击者手里再转手。到期 → 入库成证据（热度 +1）/ 被卖出（关联流言变**确证**，再也压不住）/ 被拿来敲诈。买回 2000 欧元 |
| 复仇     | 死后 **3 天**按分量掷骰：街头 25% / 精锐 45% / 精英 70% / 传奇 90% 有人找上门                                                                                                      |

**宿敌（nemesis）**：让有卡敌人逃掉、或收场 24 小时内放走活着的敌人，且确实结仇，可升成宿敌（**同时最多 2 个**）。他回来前会针对你最常用的打法做准备（7 种打法：枪 / 刀 / 格斗 / 快速破解 / 潜行 / 说话 / 技术）；用被克的打法 **+2 DV**（你不知道也照加）；可扫描/打听/撞破准备（揭穿后威胁从 3 升到 4）；杀掉/和解/彻底退场了结得 **+2 级声望**。

## 9. 城市、时间与出行

### 时钟与天气

- 时间以"从 1970-01-01 00:00 起的整数分钟"存储，最小刻度 **1 分钟**，**只能前进**；不写时间就是时间没动。
- 时段：05:00 清晨 / 09:00 白天 / 17:00 傍晚 / 21:00 深夜。
- 天气每 **6 小时**一段，由"块号 × 3 + 区域种子"哈希从权重表抽（9 张：市区/海岸/恶土 × 湿季/旱季/平季）；6 种：晴、多云、雨、雾、酸雨、沙暴。**天气只影响氛围，不给任何检定加成。**

### 期限（deadline）

任意系统都能挂期限（还债、委托、事故）。到期前 **180 分钟**"神经界面"发一条"期限将至"消息；**一次跳过 ≥120 分钟**且中间有期限时，时间会被**截在最早到期那一刻**交给玩家（不能一口气睡过去把事睡黄）。

### 场景与地点

- 场景号 `scene` 每次收场 +1；收场本身不推进时间。
- 地点：原作固定地点（`locations.ts` 10 处）+ 原作服务点 `poi:` + 原作地标 `ft:` + 剧情新地点 `place:N`。模型写新地点只能给 `{name, in: 城区中文名, note}`，**坐标由代码推算**（先贴 600 米内最近的原作路边点，否则向城区中心拉回，并与其他点至少隔 0.4 个百分点≈30 米）。
- 地图按原作底图，**1 个百分点 = 78 米**；【地点】一节列全部固定地点 + 1500 米内最近 10 个 + 最近去过 20 个，并给八方位与距离（<20 米写"就在旁边"）。

### 出行（有真实代价）

耗时 = `fixed + d × perUnit × 车速因子`（d 单位 100 米）：

| 方式       | 耗时       | 费用                |
| ---------- | ---------- | ------------------- |
| 步行       | 2 + 1.2d   | 0                   |
| NCART 轻轨 | 12 + 0.15d | 免费                |
| 出租车     | 6 + 0.18d  | ceil((20+1.5d)/5)×5 |
| 自己的车   | 2 + 0.15d  | 油/无               |
| 偷来的车   | 4 + 0.15d  | 0，但风险恒高       |

车速档因子 1→1.3 … 5→0.7；车况 damaged 再 ×1.25。**500 米内视为"走过去"**（不转成出行）。
风险：偷车恒高；步行在通缉 ≥2 星时高、夜间/黄昏为中；车与轻轨在 ≥3 星为中。
**路上偶遇**：几率 = 风险基础（低 8 / 中 18 / 高 30）+ 通缉星×4 + 夜间 6，乘频率倍数（关 0 / 少 0.5 / 常规 1 / 多 1.5），上限 60%；只在换城区时抽、一个场景最多一次。
车辆：名下最多 **6 辆**；撞两次报废；修车 = 车价 10%（最低 100）；后备箱 0–30 格；追车失败按 `stake` 扣车况或惹警。

## 10. 社会关系

### NPC 人物卡（路人不建卡）

只有发生实质互动或推动剧情时，模型才当场建卡。卡上有：诉求、底线、**秘密（只给模型看）**、装备、义体、人性、近况、共同记忆、人情/仇、认识谁、经历时间线。
- **好感 −100～100**，单条最多 ±10；模型只写方向 + 档位（small 2 / medium 5 / large 10）。
- 人物档位 mook/pro/elite/legend，属性之和必须落在 15–35 / 25–50 / 40–70 / 55–100。
- **威胁值** = NPC 有效属性总和 − 玩家属性总和：≤−8 低 / <8 相当 / ≤20 高 / >20 骷髅。
- 人情账（ledger）：谁欠谁、什么内容、可被追讨与了结（最多 12 条）。
- 共同记忆最多 12 条；**玩家可以扫描在场的人**（义眼，装着且没坏）：不调模型、不耗时间。
- 屏幕外死亡只允许原作人物且不是队员；**队员之死必须有检定失败且失败后果里点名**。
- 内容包预置 **44 张原作人物卡**（含中间人、主线/支线要角）。

### 小队

最多 **4 名**队员（玩家不算）。两种：
- **朋友型**：分成 share 1–50%，全体合计 ≤75%，委托结算时按 `floor(paid × share / 100)` 自动分账；
- **雇佣型**：周薪 1–20000，入队即付一周，**最多预付 2 期**，**欠薪一周就走**。

入队要人物卡 `met`（见过）、存活、玩家在小队面板**自己点接受**。队员状态：能出手 / 受伤 / 被抓。战斗中不能收人、不能请人走。

### 势力

五档态度（无隐藏数值）：见面就打 kos / 敌对 hostile / 中立 neutral / 友好 friendly / 自己人 family。一条指令最多变 **2 档**；升到友好及以上时，其 `enemies` 列表里每个势力各降 1 档（下限敌对）。态度生效：**见面就打 → 随时找上门、威胁 3；敌对 → 被盯梢/盘问/收买路钱、威胁 1；友好 → 有人掩护、消息灵通**；在你地盘里再 +1。势力态度还决定中间人派单星级和商店价格。

### 警方热度与悬赏

- 热度 **0–5 星**；事件基础值：杀人 2、公开动武 1、偷窃 1、破坏 1、公开骇入 1；暴力事件若公开或 ≥5 人目击再 **+1**；**没人看见就是 0**。
- 天然降温：**每游戏日降 1 星**；**换城区**当天再降 1（每日一次）；**在自家安全屋躲满 6 小时**再降 1（每日一次）；**贿赂**：1000 × 星级欧元降 1 星（5 星不可贿赂）。
- 升星来源之交：战斗录像入库 **+1**、潜入被察觉（本场景到过"搜索"档）+1。
- **悬赏**：整星 ≥**4** 且又是暴力大案 → 生成悬赏（首份 2500 × 星级，再犯 +2500），赏金猎人登场；只能靠 4 种方式了结：摆平 / 顶罪 / 伪造死亡 / 离城避风头。
- 星数影响出行风险、偶遇率、NPC 是否认出你、创伤小组是否出动（5 星暴恐机动队出动时不来）。

### NCPD 警情

时间推进时在 NCPD 辖区挂街头案子：**同时最多 3 条**，每 **6 小时**尝试挂 1 条，每条存活 **24 小时**；狗镇、恶土不出现。在场处理（本轮检定没失败）→ 赏金 + **热度 −1**；搞砸或放弃 → 撤掉没钱。

## 12. 消息与"城里的动静"

### 四个频道

`消息 messages`（人和中间人）/ `新闻 news`（N54、电台）/ `警用频段 police`（NCPD 调度）/ `街头传闻 street`。
- 叙事模型**每轮最多 2 条消息**；单条 ≤300 字；可挂委托卡附件（必须是仍可接的单）。
- 全息电话：**同一时刻只有一通在响**，响铃 **5 分钟**，超时自动记"未接"；通话记录留 20 条，消息留 40 条。
- 阅读不调模型、不耗时间；回复以"【回复消息 #n】"带进下一轮。

### 场外推演（城里的动静）

玩家看不见的地方由辅助模型（温度 0.6）自己发酵。触发条件：**这一轮收了场**，且满足其一 —— 距上次 ≥3 场、游戏时间过 12 小时、或有单子到期（节奏可调：关 / 5 场 / 3 场 / 2 场）。

推演的产物（条数只是建议，超过建议的 3 倍才截）：
- **动静** 0–3 条：街角小事 / 几个街区在传 / 上 N54 头条（头条每次最多 1 条，且**会找到玩家头上**）；状态：酝酿 / 升级 / 平息 / 结束。
- **街头传闻** 0–3 条：带真伪（属实/夸大/走样）与传播范围（一条街/整个城区/全城）；**只有正文里真有人讲给玩家听，才进玩家的街头频道**，之后 NPC 就按传的那个版本对待你。
- **播报**：N54 快讯 / 电台，进玩家的新闻栏。
- 还能顺手推：人物近况（≤4 人）、人物之间的关系、委托派单（中间人）、消息与来电、threads 步骤、原作人物在屏幕外死亡（≤1 人）。
- **头条且玩家是当事人** → 涨街头声望（0.5 / 1 / 2 级）。

## 13. 叙事层机制（这一作的"隐藏系统"）

### 提示词分四层，为缓存服务

- **L0 常驻守则**（不变，判断和写正文带全文，抽取和核对只带两条）
- **L1 阶段说明**（这一步做什么、不做什么）
- **L2 任务模板**（槽位：前情 / 最近几轮原文 / 局面 / 本轮已定的事 / 调出的旧记忆 / 设定资料 / 最近用过的写法 / 输入 / 提醒）
- **L3 输出约定**（严格 JSON、`<patch>`、纯文本）

规则模块（33 个系统各自提供）按**当前状态**决定这一轮带不带，分 `judge`（判断用）/ `narrate`（写正文用）两半，指令格式由 schema 自动生成文档。

### 上下文预算（按模型窗口自动分）

32K 窗口 → 128K 窗口线性插值；每部分有额度：规则层 4000/6000、设定资料 2000/6000、角色与硬数据 1500/3000、状态与在场人物卡 4000/12000、旧记忆 3000/10000、前情 2000/8000、原文 10000/40000、留给回复 4000/8000。
超了就**从低优先级裁起**：旧记忆 → 前情 → 设定资料 → 原文（至少留 3 轮）；裁了什么会记在"上下文查看器"里。

### 记忆：摘要 + 检索

- 一场收场后，辅助模型（温度 0.2）把这一场压成 **100–200 字**摘要（标题 ≤24 字、最多 10 个人物、5 个关键词、重要度 minor/normal/key），**原文从此不再进提示词**。
- 摘要最多 200 条；【前情】默认带最近 12 场 + 更早的 6 个关键场。
- 没进前情的旧摘要进**检索扩展层**：按人物 0.4 / 上下文人物 0.2 / 时间 0.3 / 关键词 0.5 / 意图 0.15 打分 × 重要度乘数 + 点名 0.35，每轮最多补 **3 条**，门槛 0.35。判断那一步先从候选里挑（最多 3 条），不够才补。
- **玩家可以在记忆面板改写或删掉任意一条摘要/共同记忆**（带"我看到的原文"校验，改了会打 `edited` 标记并留修改记录，最近 20 条可见）。

### 设定库（原作资料）

按地点、在场人物和输入里的专有名词，去本机官方文本库里查原作资料，单独一块给写正文；**只供参考，不算记忆，也不算已经发生的事**。超预算时整块砍掉。

### 酒馆预设（可选）

可导入 SillyTavern 风格预设：条目叠在本作提示词前面（本作规则在后），采样参数只作用于写正文那一步，`{{user}}` 用当前存档角色名，`{{char}}` 是"叙事者"；预设正则只在存档里改正文（思维链、八股词），正文被整段清空时回退原文。

### 篇幅与节奏

每轮 **100–350 字**，以对话为主，停在 NPC 说完话或需要玩家接话的地方。每轮最多 5 个建议选项、2 条内心声音（来自义体的声音要求身上真装着义体；来自不朽武器的声音要求武器栏里真有会说话的那把）。

## 15. 存档与技术规则

- 存档 = **日志（turn / check / void / background / action 五类记录）+ 快照**；用 immer patches 记账，可以从快照 `replay` 重放到任意版本。
- 每轮提交带 `requestId` 和 `baseVersion`（乐观锁），版本对不上就 409；`void` 记录用于**撤销一份记录/重开场景**，被 void 的回合在 `effectiveTurns` 里不再算。
- 存档只存在**当前浏览器的 IndexedDB**：清缓存就丢，必须用"读取存档"页导出 JSON 备份。
- 纯前端版用 Hash 路由（`#/menu`），任意子路径刷新不 404；模型服务商必须支持浏览器 CORS（Ollama 需配 `OLLAMA_ORIGINS`）。
- 模型接入：Gemini 原生（`streamGenerateContent?alt=sse`、密钥走 `x-goog-api-key`、思考内容不进正文但算输出用量）、OpenAI 兼容、Ollama；测试连接会产生费用，Gemini 测试请求最多 2048 输出 token。
- 提供方把内容拦截转成 `blocked`（不记作成功），停止生成、断流、空正文、撞到输出上限都不当完成，**不自动续写或重试**。
- 素材（原作解包）不进 Git；没解包时用 demo 素材兜底并在界面标注。

## 16. 玩法总结：这套机制想让玩家体验什么

1. **准备 > 运气**。骰子只有 1d10（2–9 占八成面），单靠属性几乎做不成事；每个"本事/义体/物品/队员/先机/情报"都能换一档 +2，所以玩的是**动手前怎么把局面做出来**。
2. **每个选择都留账**。伤口会愈合但留疤，死者有家人，流言会走样，录像 2 天后会落到某个人手里，欠的钱 7 天后有人上门，警星每天只降一星 —— 世界的记账是这场游戏真正的难度。
3. **身体是被消耗的**。义体换能力，同时永久压低人性上限；人性低于 40 就开始有失控风险，归零要么被扒光义体拉回来、要么打最后一战。
4. **城市不等你**。场外推演让城里自己发酵，传闻能把你变成另一个人（夸大的版本也照传），因此"名声"既是资源也是麻烦。
5. **模型是主持人，代码是账本**。所有数值、时间、物品、关系、死亡都由代码裁决，模型只负责让它们显得像真的 —— 这也是它能纯前端跑、还能存档回放的底气。
